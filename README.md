# 悦绘（JW AutoFill）

> Photoshop 选区填充与绘画辅助插件：生成选区即自动填充，配套一组针对选区像素的批处理工具，以及可直接切换笔刷的全局快捷键。

## 简介

悦绘由两个 Photoshop 面板和一个本地快捷键服务组成。一个是「选区填充」，负责在生成选区的瞬间完成填充或删除；另一个是「绘画工具箱」，负责对选区内的已有像素做批量处理。两者共用一份授权状态，可分别停靠、独立使用。

| 面板 / 组件 | 说明 |
| --- | --- |
| **选区填充** | 生成「新选区」时按纯色 / 图案 / 渐变 / 清除模式自动填充或删除；含主开关、混合模式、不透明度、羽化、选区改造、描边与颜色抖动。 |
| **绘画工具箱** | 针对选区像素的批处理：分块平均与渐变、同层与分层补色、特殊木刻、像素过渡与锐化、边缘平滑与消除锯齿、alpha 对齐、扣白扣黑，外加固化「蒙版同步」。 |
| **快捷键服务** | 本地组件，提供 Windows 全局快捷键：一键切换选区填充主开关，也可把画笔预设或工具箱功能直接绑到组合键，无需录制 Photoshop 动作。 |

详细图文说明见各面板文档：

> 在 Photoshop 中打开对应面板，点右上角 **⋮** 菜单 → **使用手册** 即可直接打开对应文档。

## 系统要求

- Photoshop 2022（版本 23.0）或更高版本。渐变填充与图案填充需要 Photoshop 24.2 及以上。
- Windows 10 / 11 或 macOS 10.15 及以上。
- 全局快捷键服务为 Windows 本地组件；在 macOS 上两个面板可正常使用，但不提供全局快捷键。

## 安装

1. 取得发布包（`.ccx`）。
2. 双击交由 Creative Cloud Desktop 安装；或把解压后的插件目录放入 UXP 插件目录。
3. 重启 Photoshop，在「窗口 → 扩展 / 插件」中打开两个面板。

> 全局快捷键服务随插件分发。首次在「绘画工具箱」里录制快捷键时，面板会在后台启动该服务，并登记开机自启；也可在「卸载快捷键服务」中完整移除。

## 激活与试用

- 首次使用需完成授权：任一面板右上角 **⋮** → **打开激活与试用面板**，输入激活码激活，或开启 7 天免费试用。
- 授权状态在两个面板间共享。绘画工具箱在未授权且非试用时显示锁定遮罩，执行任一功能前都会先校验授权。
- 授权面板打开期间，两个面板的菜单仅保留「打开激活与试用面板」与「使用手册」可用，其余条目暂时置灰。

## 快速开始

1. 在「选区填充」面板完成激活或试用。
2. 开启面板顶部的主开关，用套索等工具框选，即可看到自动填充。
3. 需要切换填充类型或设置描边，在「填充选项」中调整，点对应的齿轮进入子面板。
4. 需要画笔或工具箱功能的全局快捷键，到「绘画工具箱」启动快捷键服务后录制。

## 选区填充

- **主开关（默认快捷键 Ctrl+Q）**：仅在生成「新选区」时触发自动填充，加选 / 减选 / 交叉选择不触发。
- **四种填充模式**：纯色、图案（jpg / png）、渐变（线性、径向）、清除（按灰度绝对计算，白 = 全部清除）。
- **填充控制**：混合模式、不透明度、羽化，以及填充前的选区改造（平滑 / 锐度 / 扩散）。
- **描边**：内部 / 居中 / 外部，可调宽度、混合模式与不透明度。
- **颜色动态**：填充时对色相 / 饱和度 / 亮度 / 不透明度做随机抖动，支持绝对与相对两种计算方式。
- **填充设置**（浮窗）：自动删选区、更新历史源、自动关开关、自动切套索。
- **紧凑模式与专注模式**：紧凑模式让面板更省空间；同时启用「自动关开关」与「自动切套索」即进入专注模式，主开关快捷键只开不关。
- 右上角菜单：注销激活状态 · 打开激活与试用面板 · 隐藏/显示分区 · 紧凑模式 · 参数复位 · 填充设置 · 设置主开关快捷键 · 使用手册。

> 详见 [选区填充 使用说明](docs/fill-guide.html)。

## 绘画工具箱

- **快捷操作**：分块平均（含对比减弱）、分块渐变、浅线 / 深线同层补色、分层补色、特殊木刻、扣除纯白 / 纯黑、alpha 下对齐 / 上对齐 / 众对齐。
- **细节调整**：像素过渡、梯度修改、特殊锐化、高频增强。
- **边缘处理**：边缘平滑（色块边缘 / 主线条）、消除锯齿、线条加黑、极值微调（提升下极值 / 削弱上极值）。
- **蒙版同步**：把某图层的通道实时复制到目标蒙版，可建立多条同步任务。
- **笔刷热键**：录制「画笔预设 → 组合键」，全局按键直接切笔刷。
- **功能快捷键**（子面板）：把工具箱各功能与「选区填充」的子面板开关绑到组合键。
- 右上角菜单：折叠/展开所有分区 · 隐藏/显示分区 · 复位分区顺序 · 图层像素 alpha 采样 · 参数复位 · 功能快捷键 · 键盘卡死一键修复 · 卸载快捷键服务 · 使用手册。

> 详见 [绘画工具箱 使用说明](docs/toolbox-guide.html)。

## 全局快捷键

- **主开关**：默认 `Ctrl+Q`，条目长期保留，可在「选区填充」面板菜单中重录或解绑。
- **笔刷热键**：在「绘画工具箱 → 笔刷热键」选定画笔预设后录制组合键，按快捷键即可切换笔刷，无需录制 Photoshop 动作。
- **功能快捷键**：在「绘画工具箱 → ⋮ → 功能快捷键」中，为各功能按钮录制组合键。
- ⚠️ **不支持同名笔刷**：热键按画笔预设名称切换。若「画笔」面板中存在多支名称完全相同的预设，只会选中列表最上方的那支；请先把常用笔刷改成不同名称。
- 快捷键服务在后台静默运行，并登记开机自启；可随时停止或一键卸载（卸载不会删除已录制的快捷键配置）。

## 键盘卡死一键修复

系统键盘出现「突然打不出字」或「某个键不停重复」时，「绘画工具箱」菜单提供 **键盘卡死一键修复**：用鼠标点一下即可执行，全程不需要键盘输入，也不会删除已录制的快捷键。修复完成后，如需继续使用全局快捷键，回到「笔刷热键」点「启动快捷键服务」即可。

## 常见问题

**主开关开了却不自动填充？**
确认 Photoshop 工具栏的「羽化」为 0，并且生成的是「新选区」而非加选 / 减选 / 交叉。

**快捷键没反应？**
到「绘画工具箱 → 笔刷热键」确认快捷键服务处于「已就绪」绿点状态。

**切换笔刷时切到的不是我要的那支？**
多半是存在同名笔刷。热键按名称匹配，请把同名笔刷改成不同名称后再绑定。
