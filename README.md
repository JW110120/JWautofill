# JW AutoFill（易修）

> Photoshop 选区填充与绘画工具箱插件：生成选区即自动填充，配套像素级批处理算法与全局笔刷热键。

## 功能概览

JW AutoFill 由两个 Photoshop UXP 面板与一个原生快捷键服务组成：

| 面板 / 组件 | 说明 |
| --- | --- |
| **选区填充** | 生成「新选区」时按纯色 / 图案 / 渐变 / 清除模式自动填充；含主开关、混合模式、羽化、选区改造、描边与颜色抖动。 |
| **绘画工具箱** | 选区像素级批处理：分块均值 / 补色 / 木刻 / 锐化 / 边缘平滑 / alpha 对齐 / 扣白扣黑，外加「蒙版同步」引擎。 |
| **快捷键服务** | 原生组件提供 Windows 全局快捷键：一键切换选区填充总开关，并把笔刷预设直接绑到热键，无需录制 Photoshop 动作。 |

详细图文说明见各面板文档：
- [选区填充使用说明](docs/fill-guide.html)
- [绘画工具箱使用说明](docs/toolbox-guide.html)

> 在 Photoshop 中打开对应面板，点右上角 **⋮** 菜单 → **使用手册** 也可直接打开对应文档。

## 系统要求

- Photoshop 2022（版本 23.0）或更高版本。绘画工具箱的像素处理功能依赖 imaging API，在更早的 Photoshop 版本中无法使用。
- Windows 10 / 11 或 macOS 10.15 及以上。
- 快捷键服务为 Windows 原生组件，仅在 Windows 下提供全局笔刷热键。

## 快速开始

1. 安装插件（见下方「安装」）。
2. 打开 Photoshop → 窗口 → 扩展 / 插件，启用「选区填充」与「绘画工具箱」。
3. 首次使用需在「选区填充」面板完成 **激活或试用**。
4. 在「选区填充」面板开启主开关，用套索框选即自动填充。
5. 需要全局快捷键切换笔刷：到「绘画工具箱 → 笔刷热键」启动快捷键服务并录制。

## 安装

1. 下载发布包（`.ccx`）。
2. 双击由 Creative Cloud Desktop 安装，或把解压后的插件目录加载到 UXP 插件目录。
3. 重启 Photoshop，在窗口菜单中启用两个面板。

> 快捷键服务为 Windows 原生组件。首次使用「笔刷热键」时面板会在后台启动该服务并注册开机自启。

## 选区填充面板

- **主开关（Ctrl+Q）**：仅在生成「新选区」时触发自动填充；支持「自动切套索」「自动关开关」联动。
- **四种填充模式**：纯色 / 图案（jpg、png）/ 渐变（线性、径向）/ 清除（绝对计算，白 = 全删）。
- **选区改造**：平滑、锐度、扩散。
- **描边**：内部 / 居中 / 外部，可调宽度、混合模式、不透明度。
- **颜色动态设置**：色相 / 饱和度 / 亮度 / 不透明度抖动，支持「绝对 / 相对」计算。
- 右上角菜单：`注销激活状态` · `打开激活与试用面板` · `参数复位` · `设置选区填充主开关快捷键` · `使用手册`。

> 详见 [选区填充使用说明](docs/fill-guide.html)。

## 绘画工具箱

- **快捷操作**：分块平均、分块渐变、浅 / 深线同层补色、分层补色、特殊木刻、扣白、扣黑。
- **细节调整**：像素过渡、梯度修改、特殊锐化、高频增强。
- **边缘处理**：边缘平滑（仅色块边界 / 仅主线条）、alpha 下 / 上对齐、保底下对齐（alpha 对齐含背景）、线条加黑。
- **蒙版同步**：把某图层通道实时复制到目标蒙版（事件驱动 + 兜底轮询）。
- 右上角菜单：`折叠/展开所有分区` · `隐藏/显示分区` · `复位分区顺序` · `参数复位` · `图层像素 alpha 采样` · `卸载快捷键服务` · `使用手册`。

> 详见 [绘画工具箱使用说明](docs/toolbox-guide.html)。

## 快捷键服务（笔刷热键）

- 全局快捷键直接切笔刷，**不录制 PS 动作**。
- 主开关条目默认 `Ctrl+Q`（可解绑 / 重录）。
- 笔刷 → 快捷键：选笔刷 → 点录制圆点 → 按组合键（A–Z、0–9、F1–F24、符号、方向 / 空格 / 回车 / 小键盘等）。
- ⚠️ **不支持同名笔刷**：热键按笔刷预设名称切换，Brushes 面板中存在多支名称完全相同的笔刷时，只会选中列表最上方那支；请先把同名笔刷重命名为不同名称再绑定。
- 快捷键服务在后台静默运行、注册开机自启；可一键卸载（移除自启 + 删除安装目录）。

## 授权与试用

- 授权状态在两个面板间共享；绘画工具箱未授权时会显示锁定遮罩。
- 试用剩余天数在工具箱横幅显示。
- 激活 / 试用在主面板「打开激活与试用面板」完成。

## 常见问题

**自动填充没触发？**
确认工具栏「羽化」为 0，且是生成「新选区」而非加选 / 减选 / 交叉。

**快捷键没反应？**
到「绘画工具箱 → 笔刷热键」确认快捷键服务为「已就绪」绿点状态。

## 开发构建

```bash
yarn install      # 安装依赖
yarn build       # 生产构建（webpack --mode=production）
yarn watch       # 开发模式监听
```

构建产物在 `dist/`，其中 `docs/` 会随插件一起打包，供面板菜单「使用手册」打开。
