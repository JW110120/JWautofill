   - `applyBrush` 现在返回 boolean 并在笔刷名不存在时打明确日志。

## 2026-08-29 第二轮：快捷键从未注册的根因 + 卸载按钮无反应（提交于 aeafe1b 之后）

1. **根因（最重大）**：Program.cs `_configPath` 初始值是 `""`，`DefaultConfigPath` 定义了却从未赋值使用 → SaveConfig 抛 `The value cannot be an empty string (Parameter 'path')` → hotkeys.json 从未落盘 → 快捷键从未注册过。定位方法：前台运行 daemon 重定向 stdout，跑 analysis/hotkey/ws_raw_test.mjs（手写原始 TCP WebSocket 客户端），日志直接暴露错误。修复：无有效路径参数时回落 DefaultConfigPath。
2. **叠加 bug**：System.Text.Json 默认大小写敏感，UXP 推 `{id,combo,action,brush}` 小写键反序列化到 PascalCase 属性全部为空 → 快捷键即使落盘也注册不上。修复：统一 JsonOpts（CamelCase + PropertyNameCaseInsensitive=true）用于 config 的序列化/反序列化/广播；UXP 端 normalizeEntry 双向兜底。
3. **Broadcast 帧长度 bug**：原来硬编码单字节长度（假设消息<126B），改用 SendToClient 的完整长度编码。hotkey 广播新增 combo 字段。
4. **卸载按钮无反应**：用户从 dist 加载插件，dist 里没有 native/HotkeyDaemon/uninstall.bat → getPluginFolder 定位失败 → openBundled 抛异常 → uninstallDaemon 无 try/catch 全部吞掉。修复：整体 try/catch + 找不到脚本时退化为文件选择；webpack 拷贝 bat/ps1/exe 进 dist（glob 模式 to 必须带 [name][ext]，否则保留源路径）。
5. **面板热键触发反馈**：onHotkeyTriggered 回调 → 面板显示「热键触发 ✓/✗」，用户可直接观测事件是否到达（无显示=事件没到；✗=batchPlay 失败）。
6. 新 daemon exe 已编译部署到 %LOCALAPPDATA%\JWautofill\daemon（md5 417E…）+ dist；端到端验证通过（推送→落盘→回读全链路 OK，中文 \u 转义正常）。
7. **环境限制**：本会话沙箱会回收所有后台子进程（Start-Process/setsid/schtasks 均无法持久拉起 daemon，schtasks 还被安全策略黑名单禁），daemon 启动需用户点面板「安装守护进程」选 install.bat 或重启电脑（HKCU Run 自启）。
8. 之前录制的快捷键实际从未保存成功，需用户重新录制；hotkeys.json 里留了一条 Ctrl+Alt+K→多线混合 的测试条目可直接验证。
