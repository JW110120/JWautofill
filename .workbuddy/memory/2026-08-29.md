## 笔刷热键三连修（00:05）

1. **卸载守护进程无反馈**：`uninstallDaemon` 改为轮询反馈——卸载脚本第一步停守护进程，所以「已连接 → 未连接」即判定卸载成功；25s 超时未断开则提示去弹窗确认。未连接时唤起则直接提示去窗口操作。
2. **快捷键触发但笔刷没切**（根因 + 论坛确认的正确 API）：
   - 旧 `applyBrush` 用 `{_ref:'brush', _enum:'brush', _value:'preset'}` + 顶层 `name:` → 引用无效，batchPlay **静默无效**（不报错也不切）。
   - **正确 descriptor（UXP 论坛 7168 帖 #12 Karmalakas + 2127 帖 IanBarber 实例双重确认）**：`{_obj:'select', _target:[{_ref:'brush', _name:'笔刷名'}]}`。
   - **坑**：不要加 `_options:{dialogOptions:'dontDisplay'}`——实际效果相反：笔刷名不存在时会弹 PS 错误框且异常不进 catch；去掉后正常 throw 可捕获。
   - 切工具也改为标准 `{_obj:'select', _target:[{_ref:'paintbrushTool'}]}`（旧的 set currentTool 写法易抛错）。
   - `applyBrush` 现在返回 boolean 并在笔刷名不存在时打明确日志。
3. **列表 UI**：删除按钮统一为垃圾桶 `DeleteIcon`（与蒙版同步一致）；快捷键列定宽 110px 使笔刷名对齐。顺手修 `Icons.tsx` 的 `DeleteIcon` 不接收 style props 的问题（此前所有调用处传的 style 均被忽略）。
