## lineSmoothProcessor 杂点修复（SDF 平滑第三轮）
- 用户反馈：平滑效果 OK，但线外出现游离像素杂点。
- 根因：Phase C 输出 `strokeAlpha = cov * bodyBlur * bodyScale`，其中 `bodyBlur` 是原始 alpha 的**无掩码高斯光晕**，而 SDF smoothstep `cov` 在边界外会泄漏一点正值 → 光晕 × 小 cov 在线外生成游离 alpha 杂点。
- 修复：密度分支解耦——原线像素(alpha>THR)保留抛光后的真实密度（保笔压）；原为背景/孔洞像素改用「代表性密度 medOrig」而非光晕，杜绝线外杂点；同时平滑新增边缘与内部孔洞得到干净填充。cov（SDF 形状+抗锯齿）不变，几何平滑/线宽/圆角不变。
- 验证：
  - 合成杂点压力测试 test_specks_v18.mjs：撒 120 个线外杂点 → 残留 0；线保留 97.2%，线宽 20.58→20.06，AA 81.8%→85.7%。
  - 真实铅笔曲线日志 run_on_logs2.mjs：游离杂点(与原线不相连) 0，明确杂点(距线≥2px) 0；AA 89.3%，线宽 19.57→18.87。
  - test_line_smooth_v17.mjs 回归无回退：背景 99.93%、洪泛取色 100%。
- 类型检查无新错误。
- 关键文件：src/adjustments/lineSmoothProcessor.ts；验证脚本 analysis/line_vis/test_specks_v18.mjs、run_on_logs2.mjs。

## lineSmoothProcessor 游离杂点第三轮根因（本次，用户给出新线索）
- 现象（用户实测对比）：点击平滑后线条**整体轻微变细**，而**个别原线像素不受 SDF 影响仍停留在原位置**，看上去像变细线条的近外部有游离杂点。
- 根因（与上一轮「原杂点存活」不同）：SDF 由 `binaryOpen(lineMask,2)` 的 `lineMaskClean` 构建，原线被开运算削掉的边缘皮/小凸起/分支尖已**不在 SDF 内** → smoothstep cov≈0 → 输出 na==0；旧写回规则「na==0 且非 isSpeck → 保留原值」把这些原线像素**原样写回**，于是线条变细后它们在近外部残留。
  - 上一轮 `isSpeck` 只覆盖面积 < SPECK_MAX 的孤立小域，但本例残留像素属于**被 SDF 覆盖的大连通域**中「被推到线外」的部分，isSpeck 永远为 0 → 漏网。
- 修复（Phase A.5 + E.5 + 写回 na==0 分支重做）：
  1. Phase A.5 在 8 连通分量标注基础上记录每个分量的面积（lineCompSize），isSpeck 仍保留。
  2. 新增 **Phase E.5 分量级覆盖判定**：对每个原线连通域算覆盖率 cov=hit/cnt（hit=输出 na>0 的像素数）；cov ≥ COVER_MIN(0.25) → compCovered=1（该分量确实被 SDF 平滑，变细是正常结果）。
  3. 写回 na==0 分支重做：`na==0 && (isSpeck || compCovered[cid])` 才清除；并加守卫——仅当 8 邻域存在「输出空位(na<=0)」才视为外观残留清除，**被输出完全包围的（线条内部 1px 孔洞）保留**防误开洞；cov<COVER_MIN 的大分量（极细线 SDF 失效）保留原值防误删真实细线。
- 验证：analysis/test_writeback_logic.mjs 6 条分支用例全 PASS（近外部残留清除 / 内部孔洞保留 / 小杂点清除 / 极细线保留 / 正常像素保留）。`tsc --skipLibCheck` 仅余与本次改动无关的预存错误（line156 Float32→Float64 参数，原文件即存在）。
- 关键文件：src/adjustments/lineSmoothProcessor.ts（Phase A.5 标注、Phase E.5、写回 na==0 分支）。

## lineSmoothProcessor 杂点残留根因补齐（第二轮）
- 现象：上一轮修复后，用户图里仍有游离杂点。排查发现：**干净输入平滑不产生任何新像素**（验证脚本确认 0），图里的杂点其实是**原图已有的杂点原样存活**。
- 根因（更深一层）：杂点 alpha>THR 会进 `lineMask`，但被 `binaryOpen(r=2)` 从 `lineMaskClean` 移除 → Phase C cov≈0 已正确清空 strokeAlpha=0；**但 Phase E「na==0 不写、原值保留」又把原杂点 alpha 原样写回输出**（输出=输入，如 181→181）。v18 旧指标只统计「背景→新内容」像素，漏掉「原杂点存活」。
- 修复：新增 **Phase A.5 游离杂点标记**——对原 `lineMask` 做 8 连通域分析，面积 < `SPECK_MAX=10` 的小连通域（铅笔屑/碎墨点，与主线条不连通）标为 isSpeck；Phase E 写回时 `na==0 && isSpeck` 像素**连同 RGB 清零**。大连通域（主线、细线部件）不受影响，仍走「保留原值」防孔洞。
- 验证：
  - 杂点存活：修复前 195/195(100%) → 修复后 **0/195(0%)**；v18 主线保留率(不含杂点) 97.25% 前后一致，无回退。
  - v17 回归：线宽 -9.0%→-9.1%、MAE 53.7→53.8（仅随机数据噪声，无实质变化）。
  - `tsc --skipLibCheck` 项目 0 错误；webpack production 构建成功。
- 关键文件：src/adjustments/lineSmoothProcessor.ts（Phase A.5 + Phase E）；test_specks_v18.mjs 指标已增强（新增「原杂点像素存活」「主线保留率不含杂点」）；对比图 analysis/line_vis/speck_fix_compare.png。
