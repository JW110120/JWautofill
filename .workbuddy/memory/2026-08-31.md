## 守护进程静默化（加载/卸载不再弹 cmd 窗口）
- 诱因：用户设了很多全局快捷键，切换去别的软件打字时常断开/重连守护进程，每次重连都弹 install.bat 的 cmd 窗口（install.ps1 成功后 3 秒倒计时关闭），打断打字。
- 改动：
  - `native/HotkeyDaemon/HotkeyDaemon.csproj`：`<OutputType>` 由 `Exe` 改为 `WinExe`（GUI 子系统，无控制台窗口），加 `NoWarn CA1416`。
  - `native/HotkeyDaemon/Program.cs`：
    - `RedirectConsoleToFile()`：Main 首行把 stdout/stderr 重定向到 `%LOCALAPPDATA%\JWautofill\daemon\daemon.log`（诊断不丢失）。
    - `EnsureSelfInstalled()`：拷贝自身到安装目录 + 注册 HKCU\Run 自启 + 从安装目录重拉自身后退出（防重复实例抢占端口）。
    - `RegisterAutostart` / `GetFileHash` / `DoUninstall`（uninstall 走 WS `type:"uninstall"`，删安装目录）。
  - `src/hotkey/HotkeyBridge.ts`：新增 `sendDaemonCommand(type)`（发 uninstall 等指令）。
  - `src/hotkey/BrushHotkeySection.tsx`：`loadDaemon` 改为直接 `openBundled(publish/JWautofillHotkeyDaemon.exe)`（静默），反馈走 `showMessage`；`uninstallDaemon` 优先发 `uninstall` 指令（静默），未连接才回退 uninstall.bat。
- 已 `dotnet publish -c Release -r win-x64 --self-contained -o native/HotkeyDaemon/publish` 重新生成 exe（67.5MB）。
- 注意：面板仍是旧打包，用户需重新 `webpack` 构建插件才会带上新 TS；daemon exe 已就地更新。

## 主面板底部 checkbox 区间距收紧
- 现象：`.checkbox-main-container`(height:90) 内两行用子容器 `space-around` 分布，顶部/行距/底部留白约各 18px，看起来行距偏大。
- 方案（用户拍板，最利于维护）：给容器加 `padding:15px 0`（上下内边距相等）。几何上让上行下移 5px、下行上移 5px、行距缩小 10px；后续新增选项只要同步增高 `height`（约 +26px/行），行距与上下内边距仍由 space-around 自动保持相等。
- 改动：`src/styles/styles.css` 的 `.checkbox-main-container`（仅加 `padding:15px 0` + 注释），未动子容器。
- 已写入 MEMORY.md「排版规范」新增该间距规范 bullet。
