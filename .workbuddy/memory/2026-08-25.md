# 2026-08-25 工作日志

## lineSmoothProcessor.ts 算法重构（仅主线条模式）

- **原因**：用户对 v16（沿切线各向异性模糊）在目标 2(alpha不偏离)、3(毛刺削弱)、4(反复描线合成一根) 不满意。
- **新算法**：改为「拟合重建」路线（对齐 Python 原型 v15 思路，移植并加固到 TS）：
  1. 逐行提取段特征 [x0,x1, body=P90, gw=软边宽]（body 取段内 P90，保持原线最实部分→整体深浅不偏）。
  2. 跨行按中心邻近链接成笔画 track（容差=radius，允许小 gap 容错）。
  3. 沿 track 移动平均平滑 x0/x1/body/gw（窗=f(strength)）→ 去几何毛刺/粗细不均 + 磨平反复描线波动。
  4. 规则平滑剖面重建 alpha=16+(body-16)*smoothstep(dmin/gwE)，跨 track 取 max（重叠/反复描线合成一根）。
  5. 多源 BFS 就近洪泛：新覆盖像素（alpha>0 原背景）从最近原线像素取 RGB。
  6. 仅选区写回；原线 RGB 直通，背景绝对保持。
- **验证**（analysis/line_vis/test_line_smooth_v17.mjs，合成脏彩色线稿 + node --experimental-strip-types）：
  背景 99.4% / 线宽 +0.4% / 核心波动收敛 -68%(goal4) / 相邻行突变 -44%(goal3) / 整体深浅偏移 -8.5 / 新像素洪泛取色 100%。
- **删除**了不再使用的 edtDistance / structureTensorAngle。签名与 defaultLineSmoothParams 保持不变（smartEdgeSmoothProcessor 仍按 {strength,radius} 调用）。
- 验证报告 analysis/line_vis/验证报告-仅主线条平滑.md 仍描述 v16，已过时，需后续更新。

## lineSmoothProcessor.ts 真实铅笔曲线回归修复

- **用户反馈**：真实铅笔曲线（Desktop 原始.log / 平滑后.log）出现 61 个像素级孔洞/缺损，部分边缘锯齿强烈。
- **根因**：初版拟合重建仍独立平滑 x0/x1，左右边界可反向漂移；边界 smoothstep 直接落到 16（刚好被阈值裁成背景）。
- **修复**（src/adjustments/lineSmoothProcessor.ts）：
  1. 改为平滑 **中心线 cx + 半宽 hw**（几何对称，避免左右边界漂移）。
  2. 重建剖面用连续区间 `[cx-hw, cx+hw]`，以 gw 为软边带宽做 smoothstep（16→body），边缘过渡正确。
  3. 加 **不丢原线像素保底**：所有原 lineMask 像素，平滑后 alpha 不低于原 alpha，彻底防孔洞/缺损。
- **真实数据验证**（analysis/line_vis/run_on_logs.mjs）：
  - 孔洞：61 → **0**，原线像素 8123 全部保留。
  - 新增覆盖：225（与旧结果一致，但边缘连续、无锯齿缺损）。
  - 合成测试无明显回退：核心波动 -78%、相邻行突变 -29%、背景保持 99.36%。

## lineSmoothProcessor.ts 第三版：有符号距离场(SDF)平滑

- **用户反馈**：「新版平滑.log」中真实铅笔曲线出现：
  1. 两段抛物线弧及最顶端被「暴力削平」；
  2. 算法去锯齿能力完全消失；
  3. 圆弧处长出尖角。
- **根因**：中心线移动平均会拉平抛物线顶点（局部极值被均值抹成平台）；`[cx-hw,cx+hw]` 对称带状重建在中心线拐点形成「跑道胶囊」尖角；原像素 alpha 保底+小 gwE 把软边硬裁成二值。
- **重写**（src/adjustments/lineSmoothProcessor.ts）：
  1. Felzenszwalb 精确 EDT 构造有符号距离场 sd（线内为正、线外为负）。
  2. 高斯平滑 sd（σ≈2.2）去除几何锯齿与毛刺：圆角被「倒圆角」、抛物线顶点保持圆润、无削平/尖角。
  3. 原 alpha 轻抛光（σ≈1.2）后做中值归一，保证整体明暗不偏。
  4. 用 `cov = smoothstep((sd_blur-T)/band)`（T=0, band≈1px）重建反锯齿软边，再乘以抛光密度得到最终 alpha。
  5. 删除原像素 alpha 保底；写回时 na==0 直接跳过，避免硬性孔洞，同时不把锯齿边缘硬保留。
- **真实数据验证**（analysis/line_vis/run_on_logs2.mjs，原始.log vs 新版平滑.log）：
  - 线宽：19.57 → 18.82（-3.8%），基本保持。
  - 软边像素占比：4.3% → 89.4%（去锯齿能力恢复）。
  - 差异图无可见内部孔洞；365 个丢失像素均为边缘细化。
  - 顶端/抛物线弧/圆弧局部放大无削平、无尖角。
- **合成测试**（test_line_smooth_v17.mjs）：背景 99.93%、线宽 -6.1%、核心 P50/P85 230/242。反复描线合并指标较弱（-5%），是 SDF 轻抛光的取舍。
