# 2026-10-11

## 清理 dist 中无用的空预设文件（图案 / 渐变）

**现象**：插件根目录（`dist/`）出现 `pattern-presets.json` / `gradient-presets.json`，内容均为空数组 `[\n]`。

**根因**（三处联动）：
1. `webpack.config.js` 的 `copyWebpackPlugin` 把 `src/assets/presets/*.json` 拷贝到插件根目录，注释标明用途是「运行时回退读取」的默认预设。
2. 两个源文件是空数组（3 字节）。
3. `PresetManager.tryReadFromBundle()` 的判据是 `parsed.length > 0` ⇒ 空数组直接返回 null，永远读不出数据。

结论：这两个文件既空且无效；真正的预设持久化在 UXP 数据文件夹
（`localFileSystem.getDataFolder()/presets/`）。插件根目录的副本纯属死重。

**修复**：
- `webpack.config.js`：删除拷贝以上两个 JSON 的两行 pattern（含其注释）。
- 删除 4 个文件：`dist/pattern-presets.json`、`dist/gradient-presets.json`、
  `src/assets/presets/pattern-presets.json`、`src/assets/presets/gradient-presets.json`（并移除空目录 `src/assets/presets/`）。
- `yarn build` 重建验证：dist 根目录已无任何 preset 文件。

**死代码清理（已执行，经用户确认）**：移除 `PresetManager.ts` 中消费这两个文件的回退逻辑——
- `getPluginFolder()` + `tryReadFromBundle()` 两个私有方法（后者仅供前者使用）；
- `loadPatternPresets()` / `loadGradientPresets()` 中的 bundle 回退分支各一处；
- 顺带修正两处保存守卫（空数组跳过写盘）的注释，原「回退到默认预设」措辞已不成立，改为「避免覆盖已有预设」。
运行时行为不变（数据文件夹为空时仍返回 `[]`）。`npx tsc --noEmit` 通过，两个面板预设加载/保存链路无其它引用。
⚠️ 注意：其它文件的 `storage.localFileSystem.getPluginFolder()` 属**无关**调用（HotkeyBridge / BrushHotkeySection / openDocs），未动。
⚠️ 若日后要随插件分发默认预设，需恢复：① `src/assets/presets/*.json`（填入真实预设）；② webpack 拷贝 pattern；③ PresetManager 的 bundle 回退链。
