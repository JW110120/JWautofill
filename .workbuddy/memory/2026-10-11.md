## 清理 dist 中无用的空预设文件（图案 / 渐变）

**现象**：插件根目录（`dist/`）出现 `pattern-presets.json` / `gradient-presets.json`，内容均为空数组 `[\n]`。

**根因**（三处联动）：
1. `webpack.config.js` 的 `copyWebpackPlugin` 把 `src/assets/presets/*.json` 拷贝到插件根目录，注释标明用途是「运行时回退读取」的默认预设。
2. 两个源文件是空数组（3 字节）。
3. `PresetManager.tryReadFromBundle()` 的判据是 `parsed.length > 0` ⇒ 空数组直接返回 null，永远读不出数据。

结论：这两个文件既空且无效；真正的预设持久化在 UXP 数据文件夹
（`localFileSystem.getDataFolder()/presets/`）。插件根目录的副本纯属死重。

**修复**：
- `webpack.config.js`：删除拷贝以上两个 JSON 的两行 pattern（含其注释）。
- 删除 4 个文件：`dist/pattern-presets.json`、`dist/gradient-presets.json`、
  `src/assets/presets/pattern-presets.json`、`src/assets/presets/gradient-presets.json`（并移除空目录 `src/assets/presets/`）。
- `yarn build` 重建验证：dist 根目录已无任何 preset 文件。

**死代码清理（已执行，经用户确认）**：移除 `PresetManager.ts` 中消费这两个文件的回退逻辑——
- `getPluginFolder()` + `tryReadFromBundle()` 两个私有方法（后者仅供前者使用）；
- `loadPatternPresets()` / `loadGradientPresets()` 中的 bundle 回退分支各一处；
- 顺带修正两处保存守卫（空数组跳过写盘）的注释，原「回退到默认预设」措辞已不成立，改为「避免覆盖已有预设」。
运行时行为不变（数据文件夹为空时仍返回 `[]`）。`npx tsc --noEmit` 通过，两个面板预设加载/保存链路无其它引用。
⚠️ 注意：其它文件的 `storage.localFileSystem.getPluginFolder()` 属**无关**调用（HotkeyBridge / BrushHotkeySection / openDocs），未动。
⚠️ 若日后要随插件分发默认预设，需恢复：① `src/assets/presets/*.json`（填入真实预设）；② webpack 拷贝 pattern；③ PresetManager 的 bundle 回退链。

## 修复 FixKeyboard.exe 未随构建进入 dist

**现象**：插件目录（`dist/native/HotkeyDaemon/`）缺 `FixKeyboard.exe`，「键盘卡死一键修复」在打包后不可用。

**根因**：`webpack.config.js` 的 copyWebpackPlugin 覆盖了 HotkeyDaemon 主程序
（`native/HotkeyDaemon/publish/JWautofillHotkeyDaemon.exe`）与 `.bat` / `.ps1`，
但**漏了 `FixKeyboard.exe`**。该 exe 属独立子项目
（`native/HotkeyDaemon/FixKeyboard/`，被 HotkeyDaemon.csproj 用 `DefaultItemExcludes` 排除），
发布产物在 `native/HotkeyDaemon/FixKeyboard/publish/FixKeyboard.exe`（git 已跟踪，76.5MB 自包含单文件）。

**运行时预期路径**（两处一致，均为扁平）：
- `HotkeyBridge.ts:172`：`<pluginRoot>/native/HotkeyDaemon/FixKeyboard.exe`
- `BrushHotkeySection.tsx:398`：`openBundled('native/HotkeyDaemon/FixKeyboard.exe')`
- exe 内部 `Program.cs` 按 `AppContext.BaseDirectory` 读取**同目录**的 `fix-keyboard.ps1`
  ⇒ 必须与 `*.ps1` 落在同一层，**不能**放 `publish/` 子目录。

**修复**：在 webpack 拷贝列表新增
`{ from: "./native/HotkeyDaemon/FixKeyboard/publish/FixKeyboard.exe", to: "./native/HotkeyDaemon/[name][ext]" }`。
`yarn build` 验证：`dist/native/HotkeyDaemon/FixKeyboard.exe` 已落位，与 `fix-keyboard.ps1` 同层。

⚠️ **遗留（已处理）**：`dotnet-publish-windows` 技能原先只写了 HotkeyDaemon 的发布，
**没有 FixKeyboard 的发布步骤**。已补入：新增「键盘修复器 FixKeyboard.exe（独立子项目）」小节
（含完整 env 前缀命令 + 落位说明 + 「改完必须再 `yarn build`」告警），并更新 frontmatter 描述与开头项目表。
项目侧同步记入 `refs/toolchain-and-env.md`（两个原生 exe 的发布/拷贝/两步走铁律）。
