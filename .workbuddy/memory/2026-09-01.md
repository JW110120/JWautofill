## 滑块容器套娃重构（为精确控制间距）
三个面板的滑块统一改为三层容器结构：`slider-parameter-collection`（标签+数值输入+单位符号，同一行）→ `entire-slider`（parameter-collection + RangeSlider 滑块本体）→ 面板级 group 容器。

- **选区填充面板**（`src/app.tsx` 不透明度+羽化两个滑块）：原 `.slider-container` 保留作为卡片样式类，叠加新组类 `selection-fill-slider-group`；内部两个滑块各包一层 `.entire-slider` > `.slider-parameter-collection`。styles.css 补了 `.entire-slider`/`.slider-parameter-collection { width:100% }` 结构规则。
- **图案面板**（`src/components/PatternPicker.tsx` 角度+缩放）：沿用原有 `pattern-setting-item-group`（组）与 `pattern-setting-item`（外壳），在 item 内新增 `.pattern-entire-slider` > `.pattern-slider-parameter-collection`。
- **纯色面板/颜色动态设置**（`src/components/SliderControl.tsx`，四个滑块共用此组件）：原 `.colorsettings-slider-header` 升格更名为 `.colorsettings-slider-parameter-collection`（colorpanel.css 同步改选择器），新增 `.colorsettings-entire-slider`（flex column）包裹 collection+RangeSlider；外层 `colorsettings-slider-item` 与 `colorsettings-slider-group` 保留。禁用态选择器均为 item 后代选择器，嵌套加深后仍命中。

### 关键避坑
- pattern.css 原有 `.pattern-setting-item div{display:flex}` 通配后代选择器会把新容器压成横向排列 → 必须加 `.pattern-setting-item .pattern-entire-slider` / `.pattern-slider-parameter-collection` 的 flex-direction:column 定向覆盖（已写入 pattern.css 并注释原因）。
- selection-fill 的 collection 保持 block（不能改 flex row）：`.slider-label` 自身是 flex space-between 且依赖块级 100% 宽度实现「文字左、数值右」，collection 若为 flex row 会让 label 收缩成内容宽、破坏布局。
