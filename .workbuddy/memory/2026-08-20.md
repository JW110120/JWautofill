## 铅笔去锯齿功能（pencilAASmoothProcessor.ts，边缘处理分区）

**新增文件**：`src/adjustments/pencilAASmoothProcessor.ts`（processPencilAASmooth）
**面板**：AdjustmentPanel.tsx 边缘处理分区新增"铅笔去锯齿"子项（边缘平滑与线条加黑之间），参数：柔化宽度 0.5~4px(默认2)/强度%/线条阈值 64~192(默认128)/细线保护开关/细线平滑%；状态、持久化、复位、handler、UI 均已接入。

**核心算法**（消除铅笔硬边锯齿，模拟圆头笔）：
- 二值化（alpha≥阈值）→ 8SSEDT 欧氏距离场 → 按"到边界距离"重建边缘过渡 alpha
- 距离映射关键：像素网格边界圈 d≈1.0~1.41，用 `dBorder = d - 0.5`、`t = 0.5 + dBorder/wEff` 才能在像素网格上产生中间 alpha（直接 0.5+d/w 会全部映射到 255，无过渡）
- 粗细分流：连通域 maxD≤1.5px → 细线域，窄过渡(thinSoft=max(1,min(1.5,w))) + 3x3 高斯兜底（alpha 只降不抬，防止吃穿 1px 线）
- 背景衔接：EDT 同时传播"最近线外像素 alpha"作为 bgA，过渡带从 bgA 渐变到 255——周围 alpha>0 的色块/羽化带不被侵蚀、无缝衔接
- **直通 RGB 保持笔色恒定（straight alpha 正确表示），透明背景侧像素取"最近线内像素直通色"（packed premult 传播，消除黑边）；不要反预乘写回（低 alpha 会过曝成白边）**

**验证**：独立 node 测试脚本 7 项全过（斜线锯齿消除/背景保护/线内实心/1px 细线保护/色块衔接/直通色一致）；webpack 构建通过。PS 内效果待用户实机确认。

## 铅笔去锯齿 v2 修复（用户实测反馈：外描边/越描越粗/湿边/标签遮挡）

**问题**：① UI 标签（4字）用了 2 字默认 class（20px）盖住滑块；② 算法只在 mask 外圈描半透明边、内部阶梯没动；③ 多次点击越来越粗（bgA 漂移：描边像素 40→74→…→≥128 变"线内"扩张）；④ 半透明线出现"湿边"（线内水平写死 255，边缘反被抬升）。

**根因**：1) **EDT 距离算法错误**——8SSEDT 用了"距离平方的曼哈顿累加"（nd=dist[j]+1/2），平方不满足三角不等式，所有距离算错（中心像素被误判为靠近边界）。改为**带种子坐标的两遍扫描**（更新时用种子坐标重算欧氏距离平方 dx²+dy²）。
2) **背景参照漂移**——bgA 取"最近线外像素自身 alpha"，描边圈 40 成新背景→二次点击升 74。改为 bgA 用**稳定背景种子**（mask 外且距线≥1.73px，distIn2≥3，排除描边圈）传播。
3) **距离与背景分离**——mask 内距离用"全部线外像素"种子（到边界真实距离），bgAlpha 用稳定背景种子，两个 EDT_out 分开跑。
4) **锚点分侧**——IN_EDGE=阈值+30（mask 内边界，重建后仍≥阈值→mask 不内缩）、OUT_EDGE=阈值-24（描边圈，<阈值→mask 不外扩），保证幂等；半透明线 edgeIn=min(IN_EDGE,aBody) 防湿边。
5) 细线高斯窗口只统计 thin 域像素（外部描边圈不参与）→ 1px 线核心不被拉淡。
6) 过渡映射：dB 用像素中心到 mask 边界折线距离（4连=0.5、8连=0.707），mask 内 s=(dB-0.5)/wEff、mask 外固定 1px（dB-0.5），对称过渡、半高点在边界→宽度守恒。

**验证**：12 项全过（斜线削台阶+补像素+中心实心/幂等/1px 保护/色块衔接/半透明无湿边/直通色一致）。UI 标签按字数用 -3/-4 class。

## 铅笔去锯齿 v3 修复（覆盖率重建，解决"软圈阶梯/线条变细/两圈描边"）

**用户反馈**：线条变细 + 周围两圈同心 alpha 不同但每圈内部均匀 → 曲线处每圈仍是二值阶梯。

**根因**：基于 EDT 距离场的重建在像素网格上天然量化（同一圈像素到边界距离相同 → alpha 相同）→ 圈内均匀 = 软圈阶梯。SDF 无法提供亚像素连续性。

**方案（覆盖率重建 coverage）**：
1. mask 二值 → box 模糊成渐变场（0~255，r=round(softWidth*0.75)）
2. 每像素 coverage = 像素内 4×4 子采样渐变场双线性插值平均（亚像素连续）
3. **双区间映射**：mask 内 cov∈[0.5,1]→alpha∈[IN_EDGE, aBody]；mask 外 cov∈[0.2,0.8]→alpha∈[bgA, OUT_EDGE] → 圈内连续（同一圈 6+ 档位）、天然幂等（内≥阈值/外<阈值）
4. **mask 内主体保护**：只处理距边界 ≤blurR+0.5px 的边界带（blur 场峰值仅 1px 宽，主体若处理会被削淡/变细/domainMax 漂移破坏幂等）
5. **稳定背景圈不改写**（distIn2≥3）：保证 bgA 参照稳定 → 幂等

**坑**：boxBlur 归一化两处算错（mask 0/1 未乘 255；窗口面积/垂直像素数混除）——渐变场值域错误会让 coverage 全 0/全 1（无效果）或虚高（全钳制）。

**验证**：14 项全过（削台阶+补像素+主体实心/幂等/1px 保护/色块衔接/半透明无湿边/直通色/圈内 20 档连续）。

## 铅笔去锯齿 v4：基于真实采样数据的拟合（半径7px 铅笔 vs 圆头笔）

**真实数据特征**（两组采样：D型曲线 + 高曲率曲线，铅笔/圆头笔各一，半径7px）：
- 铅笔：纯 0/255 二值（无过渡）
- 圆头笔：过渡带 ±1.5px、半高 alpha≈128 恰好落在 mask 边界（宽度守恒）、过渡曲线近似线性（斜率≈83/px，非 smoothstep）；像素级：mask 内第一圈 alpha≈210、mask 外第一圈 alpha≈50、第二圈≈7

**新映射（v15 定稿）**：
- mask 内：aRecon = clamp((128 + 83*dB) * covMod, 128, aBody)，dB=到边界距离（EDT），covMod=0.85+0.3*cov（圈内亚像素调制）
- mask 外：aRecon = max(bgA, max(0, 43-40*(dBout-0.5)) * covMod)（距离驱动，稳定不随 blurR 漂移）
- blurR = max(0, round(softWidth*0.5))（默认 softWidth=2.7 拟合值 → blurR=1）
- 幂等天然成立：mask 内 alpha≥128、mask 外 ≤43-50 <128（无需 IN/OUT_EDGE 钳制）
- **UI 精简为 2 个滑块**：柔化宽度（0.5~4px 默认2.7）、强度（默认100%）；线条阈值(128)/细线平滑(0.6)固定默认，细线保护开关保留

**验证**：14 项回归全过 + 真实数据对照（铅笔输入→输出曲线 内部178 vs 真实212、外部41 vs 50、主体像素完全守恒 4318→4318）。关键教训：内部过渡斜率用 cov 驱动不稳定（曲线处 cov 形状相关），改用 EDT 距离驱动更贴合真实。

## 铅笔去锯齿 v5：真实数据精确拟合（用户要求"输出 vs 圆头笔误差<10"）

**分析结论**（第一次采样 137x249 铅笔 vs 140x251 圆头笔，半径7px）：
- 铅笔纯 0/255 二值；圆头笔 alpha 与"铅笔 mask 覆盖率"单调相关（cov→alpha 查表）
- **关键数据事实**：① 圆头笔内容相对铅笔整体位移 ~1.75px（两次描边位置不同，dx=0 IoU 仅 0.69，最佳对齐 0.911）；② 圆头笔 mask 比铅笔 mask 大约一圈（圆有笔无 428 vs 笔有圆无 54）——铅笔=像素中心采样、圆头笔=面积覆盖光栅化，128 等高线外扩 ~0.5px；③ 同一 cov 桶内真实 alpha std 30-50（光栅化散布）
- **逐像素误差<10 物理不可达**：理论下限（用真实圆头笔自身 mask 重建）过渡带 MAE 也 ~11（对齐偏差 + 散布）

**定稿算法（v17）**：
- blurR = clamp(round(softWidth*1.1), 1, 4)（默认 2.7→3）；box_blur 保持重心 → cov 的 0.5 等高线 = mask 边界
- alpha = F(cov) 分段线性查表（真实数据拟合，r=3 场）：xs=[0.075..0.925]，ys=[0,0,0.5,3.2,10.4,27.4,57.5,101.2,147.3,197.7,228.9,244.7,252.9,254.7,255...]
- **幂等锚定**：mask 内 max(128)、mask 外 min(127) → 输出>=128 ⇔ mask → 二次处理 cov 场不变 → **严格幂等**（真实数据验证 0 差异）
- **数学结论**：严格幂等 ⟺ 边界处 alpha=128；圆头笔外扩圈真实 128-197 会收敛到 127（幂等代价，视觉无碍）；mask_exp 方案（匹配外扩圈）不幂等会越描越粗，弃用

**验证**：14 项回归全过（含严格幂等）；真实铅笔数据 → 输出 vs 对齐圆头笔：过渡剖面均值误差 <10（-0.5px: 100vs109、+0.5px: 221vs224、+1px: 251vs253），逐像素 MAE 12.31（数据极限）；v15 的 MAE 27 → v17 的 12（2.2x 改善）
