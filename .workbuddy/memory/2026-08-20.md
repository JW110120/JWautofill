## 下拉 UI 统一·第二轮（弹层盖层修复 + 箭头换官方图标）

**用户反馈**：
1. 平滑模式下拉打开时，下方滑块的 number 数字显示在弹出菜单**上面**（渲染顺序问题）
2. 上一轮换的 Spectrum 小三角（`M24 14L18 20.1 12 14z`）视觉上"高度只有主面板 1/2 的小等腰直角三角形"，主面板更接近 Fluent 官方 ChevronDown 18x18（圆润下箭头）

**根因**：
1. UXP 中原生控件（input[type=number]）独立于 DOM 渲染层合成，`z-index` 对它们无效，会强制盖在 fixed 弹层之上。项目已有先例："隐藏/显示分区"模态就是给 body 加 `visibility-panel-open` 类 + CSS `visibility:hidden` 隐藏 number 输入
2. 上一轮用了 Spectrum 几何三角（viewBox 36 中 path 仅占 y14-20.1，视觉高 ≈2px），而主面板 sp-picker 箭头是圆润的 Fluent ChevronDown

**修复（AdjustmentPanel.tsx + adjustment-input.css）**：
1. MaskSyncSelect pop 打开时给 `document.body` 加 `mask-sync-pop-open` 类，关闭时移除；CSS 新增 `body.mask-sync-pop-open #pixeladjustment input[type="number"]` 隐藏规则（visibility:hidden + opacity:0 + pointer-events:none，保留布局占位）
2. caret SVG 换成用户提供的 Fluent ChevronDown 18x18 官方路径 `M4,7.01a1,1,0,0,1,1.7055-.7055l3.289,3.286,3.289-3.286a1,1,0,0,1,1.437,1.3865l-.0245.0245L9.7,11.7075a1,1,0,0,1-1.4125,0L4.293,7.716A.9945.9945,0,0,1,4,7.01Z`，渲染 16x16，fill=currentColor（适配深浅主题）

**经验**：UXP 中 fixed+z-index 只对 DOM 元素有效，原生表单控件（number input 等）会强制置顶——凡是弹层/模态都要按"body 类 + CSS 隐藏原生控件"处理；下拉箭头参考主面板 sp-picker 时应直接使用用户指定的官方图标路径，不要用自绘几何近似。

## 下拉 UI 统一·第三轮（背景色跨面板统一 + light 主题调色）

**用户反馈**：吸色发现主面板 sp-picker 下拉背景随 PS 主题自动渲染：darkest #080808 / dark #2f2f2f / light #ffffff / lightest #ffffff；light 主题 #ffffff 偏亮，改为 #e1e1e1；特制绘画滤镜下拉背景与主面板统一。

**改动（theme.ts + styles.css + adjustment.css）**：
1. theme.ts 四个主题块 + :root 兜底新增 `--dropdown-bg-color`：darkest #080808 / dark #2f2f2f / light #e1e1e1（用户调整值）/ lightest #ffffff / 默认 #2f2f2f
2. styles.css 主面板：sp-picker 用**双保险**覆盖——`--spectrum-picker-background-color(-hover/-down)` 变量 + `--spectrum-field-background-color`（继承进 shadow DOM）+ `::part(button) { background-color: var(--dropdown-bg-color) !important }`（防内部类选择器压过）；sp-menu 背景同变量
3. adjustment.css 特制绘画滤镜：`.mask-sync-select-head` / `.mask-sync-select-pop` 背景 `var(--bg-color)` → `var(--dropdown-bg-color)`（覆盖平滑模式 + 蒙版同步共 4 个下拉的闭合态与弹层）

**经验**：Spectrum Web Components 的 shadow 内部类选择器优先级高于外部 `::part`（(0,1,0) > (0,0,2)），覆盖其背景必须 `!important` 或改 CSS 变量；面板自定义控件背景改用 `--dropdown-bg-color` 后即可与 sp-picker 的自动主题渲染完全一致。
