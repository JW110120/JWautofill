# 像素算法（JWautofill）

> `MEMORY.md` 的展开页。改这些处理器前先读本文件。
> 只记**当前有效**的算法语义、铁律与「勿重走」的路线；实测数据与推导过程不再保留（需要时在台架上现跑）。

## 通用

- ⚠️ **构建不做类型检查**（`transpileOnly`）⇒ 参数/转发缺陷只会**静默失效**。改完必须端到端跑一遍对拍（见技能 `algo-param-bench`），不能只看构建 0 error。
- ⛔ **写回型处理器两条边界铁律**（凡「整层读入 → 处理 → 整层写回」都适用）：
  1. **区域判定只能用「选区掩码 > 0」**（= 写回范围），不能用「alpha > 0」（统计口径 ≠ 写回口径 ⇒ 选区/图层边缘出错）。
  2. **采样到「RGBA 全 0」的数据缺失点（图层外/全透明）必须用中心像素值顶替（边缘延拓）**，不能把 0 当真实像素送进卷积/方差（否则 `hp = 8c` ⇒ 当场饱和成白边）。
  - ⚠️ 自适应阈值类算法里，边缘伪影会**劫持统计量**、连带废掉全局行为 ⇒ 验收必须**同时看边缘区与中心区**。

## 分块平均 / 对比减弱（`blockAverageProcessor.ts`）

- 「分块」= **不连通选区各自成块**，普通模式各自求均值填平。
- 对比减弱：`factor = (coeff/255)·(强度×0.07)·t/(1+t)`，`t = |亮度−块均值亮度| / max(σ_L, 6)`；α 用同一 factor 但不乘 φ。
- **内置混合颜色带柔化**（写死、不暴露 UI、无持久化）：`φ = clamp(1 − (u−1.5τ)/4.5τ, 0, 1)`，只作用于 RGB。

## 梯度修改（`gradientRelaxProcessor.ts`）

- 写回只影响原本 `alpha>0` 的像素；末尾反预乘 pass 对「a=0 或选区外」整像素还原原始字节（预乘往返有 ±1 漂移）。
- 负值 alpha 走 blurAlpha 邻域加权均值，`a=0` 冻结 ⇒ 放缓只能向内摊，不回扩 alpha。

## alpha 对齐（`alphaAlignProcessor.ts`，当前 = v10 三档整片归一）

- **语义**：三个按钮共用同一次「**选区**直方图」，只是取不同统计量，动作都是**整片归一**：
  - **上对齐 = 选区内 alpha 最大值**（最深档）；**下对齐 = 选区内 alpha 最小值**（最浅档）；**众对齐 = 众数**。
- **实现**：直方图 = **选区本身**（不再用 halo），只统计 `a ≥ MIN_ALPHA(32)`；`target = alignUp ? maxA : minA`；写回 `na = round(a + (target − a) × rate × fade)` 覆盖选区内**所有** `a ≥ 32` 像素，**没有任何「找不到参照就跳过」的分支** ⇒ 结构上不可能有遗留；目标只依赖直方图 ⇒ 完全空间一致。
- ⚠️ **极值必须从 `a ≥ 32` 起算**：低于 32 是残留与 AA 尘埃。用户自己的稿子 AA 全在 32 以下、域内全 ≥82 ⇒ 该下限对他无副作用；若某稿 AA 落在 32~80，「最小值」会落在 AA 尾上（console 会打 ⚠️）。
- ⚠️ **已知取舍（用户选定，勿擅自加门槛）**：极值档可能是**孤立极值**（实测 1px）⇒ 整片被它带走。这是用户要的语义（他要的就是「极值」这个统计量）；真要排除孤立极值就缩小选区。console 对占比 <1% 的基准档打 ⚠️ 即可。
- ⛔ **不要引入「区间填充 / 占用量」型判据**：真实画稿（带纹理/羽化）直方图是连片的 ⇒ 这类判据**恒真**，会把候选吃光（曾 100% 吃光 ⇒ 修改像素数 = 0）。**保护规则越少越好**。
- ⛔ **选目标也不要用「连续达标段」**：段会被抹成一大条、代表值落回基准附近，选不出「另一档」。
- ⛔ **勿重走**：v1~v6「逐像素多尺度环带参照」（链上有结构性漏网点）；v7「全局平台基准」（被两条保护吃光，0 改动）；v8「基准=众数的单侧写回」（在「内容全在众数一侧」的稿上恒为空转）；v9「同侧计数最多的一档 + 规模门槛」（用户明确否掉）。任何「只动偏离基准那一侧」的设计都会在「内容全在基准一侧」的稿上空转。
- ⚠️ **语义不确定就先问，别猜统计量**（v8/v9 都因猜错统计量被返工）。edge 模式参数 = `mode/edgeMedianRadius/lineSmoothStrength/lineSmoothRadius`；`toggles.preserveDetail` 与 `highFrequencyEnhancer.intensity` 是别的功能同名物，勿误删。

### 极值微调（`processExtremeAlign`，线条污渍专用）

- 两个按钮（APP 面板「边缘处理」分区最下方）：**提升下极值** `raiseLow` = 上对齐（只增不减）/ **削弱上极值** `weakenHigh` = 下对齐（只减不增）。
- **与旧 v5 环带参照的唯一差别：作用通道 alpha → RGBA**。四通道用同一套算法各自独立跑，三条口径：
  - ① 判「哪些像素属于线条」的闸门**恒为 `alpha ≥ 32`**（线条几何由 alpha 定义）；
  - ② 环带直方图 / 参照簇 / 平坦拦截 / 共识 / 补判 / 写回全用**该通道自己的值** ⇒ alpha 通道与旧版逐字节相同；
  - ③ 写回 `out[di*4+ch]`，每通道各自带方向闸门。
- ⚠️ **两处刻意取舍（由通道语义决定，不是简化）**：
  - ① 旧版的「本层邻域」护栏（`bandMax > v + 60` 跳过）**只对 alpha 通道生效**：alpha 有真实的「层」；RGB 没有「层」语义，**通道落差本身就是污渍**，照搬会让偏离 >60 的色斑整个被跳过。
  - ② 参照高端区间的下界由 `minAlpha` 改为 **0**：RGB 通道值可落在 0~255 任意处，夹 32 会让深色线条（如 RGB=30）找不到参照。
- 实现要点：区域 = 选区 bbox + halo；环带参考像素**不受选区限制**；两遍处理；参照场共识半径 6（削弱取窗口内计数达标的最低参照、提升取下中位数）；补判门槛取「参照量程/2」这类有语义的锚点。四通道临时数组只分配一次。

## 消除锯齿（`aliasSmoothProcessor.ts`）

- 管线：覆盖率重建 `mask(alpha≥thr)→box 模糊→4×4 子采样 cov`，`aRecon = 本体不透明度 × profile(cov)`。
- **四条不变量**：① 阈值取「选区内 alpha 直方图众数/2」，只依赖胜出档下边界；② 本体不透明度由 EDT 从「距轮廓 ≥2px」的种子传播（窄条 ≤5px 整段当种子）、**硬性封顶 `aRecon ≤ 本体`**；③ 内侧只削不抬、外侧只补不削；④ 锚定 mask 内 ≥thr / 外 ≤thr−1 ⇒ 输出 mask 不变 = 严格幂等。
- 细线（≤4px）走**几何重建**：游程 → 链 → 平台中心插值 → 刚性带宽（众数厚度）→ 墨量守恒 `ink·cov/Σcov`。
- 铁律：
  - 墨量跨距取**几何区间**（取 mask 游程会让肩部掉出 mask、墨量逐轮流失）。
  - 幂等闸门 = 以本行游程内最大 alpha 为基准，窗口内出现 0.25~0.75 基准像素的行过半即判「已平滑」（只认领不改写）。「有任何中间 alpha」会被硬边毛刺全拦掉；用全链最大则压感渐变整段误判。
  - ⚠️ `estimateBodyLevel` 直方图必须**按墨量投票**（`hist[a>>3] += a` 而非 `++`；细线毛刺像素比本体多 ⇒ 按个数投票会落到毛刺档）。

## 「仅主线条」边缘平滑（`lineSmoothProcessor.ts`，当前 = V7 中轴重建）

- 管线：A 开运算+SDF（双 Felzenszwalb 精确 EDT）→ A.5 原线 8 连通域（面积/小杂点）→ B 高斯（σ 几何 / σ·0.55 密度抛光）→ 中值归一 → C 多源 BFS + `cov = smoothstep(sdB/band)` → D 去孤立点 → E.5 分量覆盖率 → E 写回。
- **窗口化**：只算「选区包围盒 + halo」，`halo = max(8, 2·kr+8)`，`kr = ceil(3σ) ≤ 10`（大幅提速）。⚠️ 语义代价：E.5「分量覆盖率」是连通域级统计量，窗口化后跨边界连通域判定可能与旧版略有差异；方向恒为「新保留、旧清除」（偏保守、不误删）。
- ⚠️ **细线失效已修**：旧版 `binaryOpen(r=2)` 按结构元宽度筛（线宽 <5px 一律抹除）、σ 与细线半宽同量级、E.5 连通域连坐 ⇒ 细线整段归零。现行用**面积开运算**取代半径开运算 + **逐像素自适应 σ**（`σ ≤ 0.56 × 该处结构线宽`，窗口存在性用积分图 O(1)/像素）。
- ⛔ **已证伪的判据**：用「像素自身的 EDT 距离」当线宽 —— 任何形状的边界像素到背景都只有 1px ⇒ 粗线边缘被误判成细线 ⇒ σ 压到最低档 ⇒ 平滑能力掉到 1/4。判据必须问「**附近有没有足够粗的结构**」，不是「这个像素自己离边界多近」。
- ⛔ **抗锯齿带宽 `band` 必须取格子尺度定值**（≈0.30，不随 σ 缩放）：掩码最外圈像素的 `sdB` 恒 ≈0.5（与 σ 无关），band 稍宽就会让最外圈每轮被乘一个 <1 的系数 ⇒ **纯等比衰减、连点变细直至断裂**（碎裂棘轮）。
- ⛔ **V7 两条保墨铁律（缺一则逐遍墨量单向漂移）**：
  - ① 密度源用横截面「**保墨平均** `mp = Σalpha·step/(wl+wr)`」，**绝不用峰值**（峰值作密度源 ⇒ 每横截面被抬到自身峰值、只升不降）。
  - ② 未覆盖（`aValid=0`）像素的密度抛光必须「**掩码归一** `bodyBlur = blur(alpha·m)/blur(m)`」，绝不用 `max(alpha, blur·scale)`（`max` 单向 ⇒ 棘轮主因）。
  - ⚠️「首要不伤害」护栏阈值 `0.35` **不可放松**（0.55/0.75 ⇒ 棘轮加剧）。
- ⚠️ 新代码**禁用 `Math.hypot`**（本仓 target es5 默认 lib 无 `hypot` 且它不被 TS 转译）⇒ 一律 `Math.sqrt(x*x+y*y)`。
- ⚠️ 已知代价：≤4px 线现在是「原样保留」而非「被平滑」（数学上 σ 必须 ≤0.4×线宽，不可行）⇒ 该类细化抗锯齿应交给 `aliasSmoothProcessor` 的细线几何重建。

### 宽度拉平（`flattenRadius`，2026-09-18 落地）

- **为什么需要它**：SDF 高斯拉不平粗细波浪 —— 边界信号经尺度 σ 低通后剩余系数 `exp(−2π²σ²/λ²)`，而 σ 被线宽封顶 ⇒ σ 与 λ 差 30~100 倍，**算子尺度不匹配、调参无解**。
- **实现（偏置式，不做几何重采样）**：接入点 = Phase A 之后、Phase B 之前；A.5 顺带统计分量包围盒。脊线取样 → 逐分量隔离 → 归一化散播 → box 级联低通 → 细支门槛 → Δ 偏置（在「双线性采样读值」处施加，不改写 sd 场）→ **中轴跟随**（分侧修正：`左轮廓内推 = δh − δc、右轮廓内推 = δh + δc`，δc = 中轴相对其低频的位移）。
- ⚠️ **落地期踩过并已修的坑**（都要记牢）：
  1. **双线串味**：散播半径不能过大（改 `maxHalf/(2·FLAT_GRID)`）；box blur 改成**纯卷积求和**（不归一化）、值域/权重域分别模糊再相除。
  2. **系统性变细**：`FLAT_CLAMP_FRAC` 必须 **0.50**（0.35 会绑住窄相位 ⇒ Δ 均值 ≠ 0 ⇒ 每轮净减）。
  3. **T 形细支被撑胖**：加 `FLAT_BODY_RATIO=0.35` 归零。
  4. **halo 必须含 `FLAT_HALO`**，否则散播支撑被截断、选区边缘 Δ 失真。
  5. **归一化低通必须连权重一起模糊**（`blur(H1·w)/blur(w)`）。
  6. **限幅必须对称**（上界 `±0.50·ref`）；**参照用「双侧邻域最大半宽」**（不能用普通盒状最大值，否则长细支根部被误判成凹陷而撑胖）；**重分配量必须封顶为本次拉平量 `|Δ|`**（从定义推出的恒等式 `|δc| ≤ |δh|`，能从定义推就别选阈值）。
  7. **沿轴通道步长易写反**（扁平下标 `k = gy·gw + gx` ⇒ 沿 y 的步长是 `gw`）；写反的症状是**所有「应逐字节一致」的场景一起大面积偏离** ⇒ 先跑「应零差异」的用例组当探针。
- ⚠️ 判据：「不该动的笔画有没有被动」**必须量轮廓位移**（墨迹外沿 `alpha≥32` 的最左/最右逐行 ΔL/ΔR），不能看字节差（会被「绝大多数像素没变」稀释）。

## 命名与参数链

- 「轮廓平滑」管边缘磨多圆（受线宽封顶，键 `lineSmoothRadius`，**刻意不改名**以免老预设失配）；「宽度拉平」管粗细起伏多大尺度（不受封顶，键 `lineSmoothFlatten`）。
- ⛔ **新增参数必须打通「面板 → 转发 → 处理器」整条链**（约 10 处，漏一处即静默失效）：接口字段 → 默认值对象 → 面板 state → 预设恢复 → 持久化 values → 持久化 deps → 复位 → 调用点传参 → 拖拽量程表 → switch case → handler ×2 → JSX 滑块行 → helpTexts 键。
- ⛔ lineSmoothProcessor **自包含、零 import** ⇒ 可把「只改一个常量的副本」放到任意目录直接 `import`，用同一台架做「单常量敏感性扫描」（通用手法）。

- 对拍台架是本地草稿（方法与新增脚本指引见技能 `algo-param-bench`）。改完**必须同时报**「回归 diff vs 旧版」与「作用量 vs 原图」——只报其一会漏判（如「每条线都对但整体平滑能力退化」）。
