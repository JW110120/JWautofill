## 「合并图层/合并组/删除图层 仍弹『获取』当前不可用」+ notify 汉化补全

### 问题 1 根因（不是模态碰撞，是 get 目标已失效）

`-25920` 有两个**互不相干**的成因，`executeAsModal` 只挡得住第一个：

| 成因 | 机制 | `executeAsModal` 能否挡 |
|---|---|---|
| ① 模态碰撞 | 宿主握着模态作用域时裸发命令 | 能 |
| ② **get 目标失效** | 拿**已失效的 `layer._id`** 逐条 `get`（合并/合并组/删除一次性让一批 id 失效） | **不能**（我们本来就握着锁） |

三个病灶：
1. `MaskSyncEngine.buildLayerTree` —— `refreshLayerSnapshot()` 读失败时**原样返回旧缓存**，调用方无法区分 ⇒ 拿「结构已变、内容还是旧的」快照去逐 id 发 `get`（40/批，一条失效 id 就是一屏黄条）。
2. 两处 `_options.dialogOptions` 用 `dontDisplay` —— 只挡**对话框**，命令**出错**时仍刷黄色通知；只有 `silent` 才静默（`psBrush.ts` 已踩过同坑）。
3. `LayerInfoHandler.probeChannelState` / `HotkeyBridge` 两条工具探测同样用 `dontDisplay`，且分别是「每条 select/delete/make 后 300ms」与「1s 巡检 + 每条通知」的高频入口。

### 修复（9 处）

- `layerTreeSnapshot.ts`：新增 `refreshLayerSnapshotEx()` → `{ snap, fresh }`；旧接口保持「返回旧缓存」的语义不动（下拉不清空）。
- `MaskSyncEngine.buildLayerTree`：返回类型 `LayerTreeEntry[] | null`；只接受**可信**条目（调用方给条目时要求 `!isLayerSnapshotDirty()`，自取时要求 `ex.fresh`）；不可信/异常一律 `null`，**不再返回 `[]`**（`[]` 与「文档没图层」不可区分）。
- `reconcileTasks`：`if (!entries) return false;` —— 否则一次忙碌窗口会把任务的 sample/target 引用全清空。
- `fetchLayerNamesByIds` / `fillUserMaskFlags`：`dontDisplay`→`silent`（descriptor + batchPlay 两处），命中 `_obj:'error'` ⇒ `invalidateLayerSnapshot()` + `break`（不再把 N/40 批发完）。
- `reconcileStructureIfNeeded`：走 `Ex` + 要求 `fresh`。
- `AdjustmentPanel.refreshMaskSyncOptions` / `refreshMaskSyncAndReconcile`：走 `Ex` + `fresh`；`!tree` 直接返回（不再 `reconcileTasks(undefined)` 二次建树）。
- `psProbe.debouncePsProbe`：忙碌判据 `isPsBusy() || psBusyInProc() === 1`（时间窗是否定式，`'Lvl '` 是宿主自报的肯定式；`-1` 放行，旧 .8li 行为不变）。
- `LayerInfoHandler` 两条通道 get、`HotkeyBridge` 两条工具 get：`silent`。
- 新增 `[蒙版同步] …⇒ 本轮跳过逐 id 查询` 节流日志（1.5s），真机看到它 = 保护生效。

### 问题 2 汉化

- `constants/blendModes.ts`：新增 `blendModeLabel()`（枚举→中文，大小写不敏感，查不到返回**空串**，绝不回漏原文）与 `blendModeValue()`。
- `BrushHotkeySection`：`blendMode` 分支 `blendModeLabel(info.brush) || '未知模式'`（`info.brush` 承载的是 `.8li` `KH_BLEND_DEFS` 的**枚举值**，不是笔刷名）；`entryDisplayName` 补 `blendHotkey → 混合模式热键`（否则冲突提示显示「已被「1」占用」，`brush='1'` 只是开关标记）。
- `AdjustmentPanel.formatSyncState`：`reason` 可能是复合串（`sample-pixels-failed:comps=3`）⇒ 按首个冒号取 code 再查表，查不到给中文兜底，**不再把内部代码/宿主原文漏到界面**；`benign` 判据同步改用 code。
- `docs/modal-scope-audit.md` 新增第六节（两个成因对照表 + 三病灶 + 九行修复表 + 验收要点）。

## 面板菜单与快捷键 UI 重排（同日第二轮）

用户三条要求：① 删掉 APP 菜单「设置主开关快捷键」，原处新增「自定义快捷键」子面板，与绘画工具箱「功能快捷键」**完全同款**（样式/通知/隐藏数字输入/滚动条），把选区填充的全部快捷键移植进去；② 混合模式热键的 notify 从「笔刷热键」折叠区底部移到 **APP 面板「选区平滑」分区上方**；③ 菜单里「参数复位」与「填充设置」分开，填充设置与新子面板同组。

做法：
- **一个组件两处用**：`hotkey/FuncHotkeyPanel.tsx` 增加 `scope?: 'toolbox' | 'app'`。scope='app' 标题「自定义快捷键」、只显示「选区填充」组（主开关 / 套索 / 清除 / 拾色器 / 临时吸管 / 混合模式热键 / 纯色·图案·渐变面板开关）；scope='toolbox' 只显示快捷操作 / 细节调整 / 边缘处理。差异仅限「标题文案 + 分组过滤 + 两处行动指引（热键暂停时去哪开开关）」，其余全共用 ⇒ 样式/滚动/通知天然一致。
- `MenuManager`：删 `setMainHotkey` + `spacerApp3`，新增 `appHotkeys`（回调 `onShowAppHotkeys`）与 `spacerApp4`；参数复位独占一组，`appHotkeys` + `appFillSettings` 同组。`app.tsx` 删掉 `setMainHotkey()` 方法（含 4 个只为它引入的 bridge 导入）。
- `app.tsx`：`isAppHotkeyOpen` 状态 + `openAppHotkeyPanel/closeAppHotkeyPanel`；body 类 `app-hotkey-panel-open` 由 `syncFloatPanelClasses()` **派生**（含 gutter 补偿 + `overflow-y:hidden`），参数复位时保留开合态；子面板挂在 `.app-root` 层（浮窗图层之后）。
- 层级坑：`body.app-*-panel-open #app .float-overlay { z-index:100000 }` 会把子面板一起抬到 100000，与浮窗同档后退回 DOM 顺序决胜、反把浮窗压住 ⇒ 追加 `body.app-… #app .float-overlay.func-hotkey-overlay { z-index:9999 !important }`（特异性 1,3,1 稳过）。
- 混合模式 notify：`app.tsx` 订阅 `onHotkeyTriggered`（只认 `action==='blendMode'`），`blendHotkeyNotify` state + 5s 自动消失，渲染在「选区平滑」折叠区**上方**（`.notify-bar notify-bar-ok/-fail`，与平滑错误条同款）；`BrushHotkeySection` 删掉同名分支与 `blendModeLabel` 导入。通知条显隐并入 `smoothErrBarVisible` 的重排兜底。
- **跨 JS 上下文的数据陈旧**：两块面板各有自己的 `cachedConfig`，而原生 `config` 只落盘不广播（keyhook.c）⇒ 在 A 块录完、B 块用旧列表回写会整份抹掉。新增 `HotkeyBridge.requestConfigRefresh()`（发 `getConfig`），子面板挂载时在**订阅之后**调用。`applyBlendModeHotkey` 的反查也改用 `blendModeLabel()`。
- CSS：`common.css`/`input-fix.css` 各补 `app-hotkey-panel-open` 一组规则；`adjustment.css` 快捷键行与子面板外壳块标注「两块面板共用」并说明为何不搬去 common.css（同一份 bundle，adjustment.css 加载即注入文档）。
- 文档：`docs/fill-guide.html`、`docs/toolbox-guide.html` 同步菜单与分组描述。

校验：`tsc -p tsconfig.check.json` = 143 行（基线不变，改动行 0 新增）；3 个 guard 全过；`yarn watch` 已自动重编，`dist/bundle.js`（5239826 B / 12:33）已复制到 `Adobe Photoshop 2026\Plug-ins\dist\`。⚠️ 待真机复测：子面板外观/滚动条/通知、数字输入是否被隐藏、混合模式 notify 位置、两面板交替录制不互相覆盖。
