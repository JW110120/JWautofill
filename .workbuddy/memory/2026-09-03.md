## number-input 下越界修复（PS 版本差异，非分辨率）
- 现象：数字输入框在办公室 PS 27.8 下「下越界」（原生控件下沿溢出容器），家里 PS 27.10 正常；
  用户排查定位为 PS 版本差异（自 27.9 起宿主会裁剪原生控件，不再越界），与分辨率无关。
- 根因：common.css 的 .num-input-row 容器被改成 height:24px 且 input 也 24px（等高、零缓冲），
  旧版 PS(≤27.8) 不裁剪原生控件 → 下沿溢出。原定稿设计本就是「容器32px高 + input高24px」留4px上下缓冲，
  期间被无意改小导致回归。
- 修复（src/styles/common.css，顺带满足用户「宽度24→32」要求）：
  ① `.num-input-row` height:24px → **32px**（高于 input 留 4px 上下缓冲，防旧版下越界）；
  ② 同文件 input `width:24px → 32px`（字段加宽，用户明确要求）；
  ③ 同步更新 common.css 第4节注释、gradient.css/pattern.css 中「24px」数字输入说明为「宽32×高24、容器32留缓冲」。
- 验证：rm -rf dist + webpack production（exit 0）；bundle.js 逐条核验
  `.num-input-row{...height:32px...}` 与 `.num-input-row input[type=number]{width:32px;height:24px...}` 均已注入。
- 一致性：MEMORY.md「UXP 避坑」补 PS 版本差异说明；「布局宽度」数字输入由「统一24px」改为「宽32×高24、容器32留缓冲」。
