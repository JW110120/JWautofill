## APP 主面板两处布局修复
- 缝隙根因（像素实测）：选区选项展开后，末行 .row-between 的 10px margin 穿过无 padding/border 的 .expand-content-expanded 与 .expand-section 折叠到分区盒外；UXP 不绘制该悬空 margin 区域的背景，露出原生深色底（实测 rgb(29)），10px 深色缝隙。收起时 .expand-content 的 overflow:hidden 挡住折叠链故不出现。修复：.expand-content-expanded 首行 margin-top:0 / 末行 margin-bottom:0。
- info 区叠输入根因：info-plane position:fixed 在滚动容器内做覆盖底栏，UXP fixed 压不住后绘制的原生 number 输入。修复：主面板重构为 .selection-fill-container（flex 列，无 padding/overflow）> .app-scroll-area（flex:1 + min-height:0 + overflow-y:auto + padding:10）+ info-plane 流内底栏（flex:none, position:relative）；copyright 改 absolute bottom:3px。滚动内容被裁剪，物理上不可能再叠。
- 顺带：死选择器 #app .container::-webkit-scrollbar / body.secondary-panel-open .container（#app 无 .container 类）改为 #app .app-scroll-area。

## 混合模式行重叠失效修复
- 症状：app-blendmode-container（margin-bottom:-12px）不再压住 slider-container 上缘，两容器紧贴。
- 根因：布局重构把内容从 flex 列父容器（原 .selection-fill-container）挪进块级 .app-scroll-area 后，-12px 与 slider 的 0 上边距参与块级 margin 折叠，UXP 折叠结果算 0 → 重叠消失。flex 项间 margin 不折叠，故旧结构正常。
- 修复：.app-scroll-area 补 display:flex; flex-direction:column（还原旧布局上下文）。安全前提：滚动区直接子元素无「相邻双方 margin 均非零」对（blendmode -12/0、slider 0、expand-section -1/0），flex 化不引入间距回归。
- 教训：UXP 下负 margin 重叠设计依赖 flex 项语义，滚动/布局容器改动时必须保持 flex 列。
