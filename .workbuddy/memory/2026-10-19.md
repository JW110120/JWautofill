## 键盘快捷键大面积失灵修复（0x0139）+ 清除模式/混合模式热键

**背景**：用户在 3440×1440 低配机实测：初次加载插件，笔刷热键分区开关显示"开"但已录快捷键无效果；功能快捷键子面板标题下提示"热键已暂停"；双击重录时按键无法录制。

**根因链（一个根因解释两个 bug）**：`json_str`（plugin_main.c）逐字拷贝引号内字符**不反转义** → `kh_set_config_path` 调用点漏调 `kh_unesc` → C 侧存双反斜杠路径 → 回帧四倍转义 → 面板 `daemonConfigPath !== requestedConfigPath` 恒真 → **每帧重发 setConfigPath** → C 侧"路径没变也重载"再广播 → ~1400 次/秒无限回路 → 面板 JS 线程被 config 广播帧洪水淹没（热键事件排队=按了没反应）+ 晚挂载的 FuncHotkeyPanel 等不到 hotkeyState 帧（armed 无跃变不播）→ 初值 false 常驻（显示"已暂停"并拦住录制备闸）。

**修复**
- C 侧 `keyhook.c`：`kh_handle_message` 四个 `json_str` 调用点补 `kh_unesc`（setConfigPath 含 0x0139 详细事故注释、recordStart、armDelete、repairKeyboard）；build.sh 零告警；PiPL 往返校验过。
- UXP 侧 `HotkeyBridge.ts`：config 帧路径未对齐时重发 setConfigPath 加 1s 最小间隔（`lastPathResendMs`，防御未来回路）；`hotkeyArmed` 初值 `peekPersistedArm() ?? true`；两面板（FuncHotkeyPanel/BrushHotkeySection）在 WS 连通后主动 `requestHotkeyStatus()`。

**新功能 1——专注模式 Shift+E 清除模式**：`HotkeyBridge.ts` 新增 focusClear 系列（`FOCUS_CLEAR_ID='focus_clear'`、默认 combo `Shift+E`、`ensureFocusClearEntry/setFocusClearActive/getFocusClearCombo/setFocusClearCombo`）；`handleHotkey` 的 focusClear 分支 = `requestMainToggle`（专注模式只开不关）+ `requestClearModeToggle`。跨面板总线新建 `src/utils/ClearModeBus.ts`（settings/clear-mode-toggle.json，token 去重）；app.tsx componentDidMount 订阅执行 `toggleClearMode()`、syncFocusMode 同步 `setFocusClearActive(on)`。FuncHotkeyPanel「选区填充」组专注模式下新增"清除模式"行。

**新功能 2——混合模式热键（Alt+Shift+字母改面板混合模式，不改图层）**：C 侧 `keyhook.c` 新增 `KH_BLEND_DEFS` 内置表（24 条，Adobe 官方快捷键全覆盖；Darker/Lighter Color 无快捷键故不在表）；`blendHotkey` 标志条目（combo='1'=开）**不参与匹配**（否则吞用户数字键），开启时装载内置表（action='blendMode'、brush=PS 枚举值、id='blend_hotkey'），用户显式录制的同名 combo 优先；钩子吞键 ⇒ PS 收不到原生混合模式快捷键。UXP 侧 `BlendModeBus.ts`（settings/blend-mode-toggle.json，载荷 PS 枚举值）+ app.tsx `applyBlendModeHotkey`（BLEND_MODES 反查中文名写 state）+ FuncHotkeyPanel「选区填充」组最下方自绘 switch 行（`renderBlendSwitchRow`，`.hotkey-entry-switch`/`.hotkey-entry-row-static`，adjustment.css）；BrushHotkeySection 的 `onHotkeyTriggered` 补 focusClear/blendMode 反馈文案。

**验证**：tsc 前后错误集逐行 diff 一致（156 条全为既有：缺 UXP 类型声明桩等），零新增；`yarn build` 成功（仅 3 条既有 asset 体积 warning）；bundle 内含新 CSS 两类/混合模式热键文案/requestHotkeyStatus；adjustment.css 注释括号结构手动扫描 OK；.8li 二进制含 24 个唯一 `Alt+Shift+X` 串与源表一致；BLEND_MODES 反查覆盖全部 24 枚举值。
