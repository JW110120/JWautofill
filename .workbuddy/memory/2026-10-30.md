## 0x0224 — 混合模式热键「按当前工具临时让位」

**用户诉求**：混合模式热键接管了 Alt+Shift 表，画笔工具下按 Alt+Shift+J（线性光）改的是 APP 面板的
选区填充混合模式，而没改画笔工具的混合模式。要求：开关开着时，当前工具属于
画笔/铅笔/渐变/油漆桶/涂抹/模糊/锐化/仿制图章/图案图章/历史画笔/历史记录艺术画笔 ⇒ 临时关闭；
切回套索 ⇒ 恢复；原本关着的开关不许被自动打开。

**做法**（原生让位位，不碰用户配置）：
- `keyhook.c`：新增 `g_khBlendYield` 原子位 + 入站 `{"type":"blendYield","on":true|false}`；
  三处同时让位 —— LL 钩子命中放行（不吞/不广播）、`kh_hk_sync` **不注册** blendMode 条目
  （注册即被系统摘键，钩子放行无效）、轮询兜底与 `kh_hk_fire` 不再广播；`hotkeyState` 增 `blendYield`；
  `kh_cli_add` 与卸载时归零；`KH_VERSION` → 2026-10-30.1，`jw8li_version` → 0x0224。
- `src/hotkey/blendGuard.ts`（新）：名单 + 中文名 + 单例 store（`useSyncExternalStore`），
  `noteToolForBlendYield` 是唯一喂点（null 不喂）；`recompute(resend)` 只在结论变化时发 WS（配置帧那条路 resend）。
- `HotkeyBridge.ts`：`setBlendHotkeyYield` / `replayBlendHotkeyYield` / `sendBlendYieldFrame`，onopen 重放。
- `app.tsx`：三条喂点（select 快通路无前置条件 / pollToolChange / pollSmoothToolGate）；
  `syncToolWatch` 增加 `needBlend`；`syncSmoothToolWatch` 让位（`!blendActive`），
  `pollToolChange` 的闸门供给条件放宽到 `pen.enabled || polySnapEnabled`；订阅 onConfig 感知开关翻面。

- 产物：`yarn build` 通过（仅既有体积告警）；`build.sh` 零告警、PiPL 往返一致；
  `.8li` 已覆盖部署到 `C:\Program Files\Adobe\Adobe Photoshop 2026\Plug-ins\`（部署前 PS 未运行）。

**待用户验收**：画笔工具下按 Alt+Shift+J 应改画笔的混合模式；切回套索应恢复改面板混合模式；
开关原本关着时切到套索不应自己变开。排障看 `pi8li.log` 的三行日志（让出/放行/不注册）。

## 追加：工具 ID 拼错误（用户用 Alchemist 抓 API 指出）

- **根因**：历史记录艺术画笔的真实工具 ID 是 `artBrushTool`，`artHistoryBrushTool` 在 PS 里不存在。
  旧代码三处都写了错的/全小写的：`blendGuard.ts`（`arthistorybrushtool`，且整表小写）、
  `HotkeyBridge.ts` 的 `TOOL_TYPE_CN`、`app.tsx` 的 `AUTO_OFF_TOOLS`（一条死条目）。
- **口径**：工具 ID 一律驼峰，除第一个单词外每个单词首字母大写（`gradientTool`、`cloneStampTool`）。
- **改法**：名单按真实 ID 写；匹配仍**两边归一化**（`BLEND_YIELD_SET` + `TOOL_CN_NORM`），
  防止某个 PS 版本大小写出入导致静默失效；`blendYieldToolCn()` 取代原来在 `recompute` 里的内联查表，
  未知名返回 null（文案退回「当前工具」）。`AUTO_OFF_TOOLS` 删掉死条目并把 `artBrushTool` 注释改对。
- 产物：`yarn build` 通过；bundle 里 `artBrushTool` ×4、`artHistoryBrushTool` ×0。原生未改（.8li 不用重编）。
