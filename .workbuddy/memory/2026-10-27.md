# 0x020A / 引擎 0x013A：Alt 临时吸管三条 BUG

用户自测（jwwh-15932.log，22:29–22:35）后报出，0x0209 的工具闸门拆分与光标钉住**已验证有效**
（日志 `sureNo=1 edit=0 toolOk=0` 在切走工具后 1s 内出现）。

## 一、HUD 在「填充完选区 + 挪动光标（未落笔）」时短暂闪现

### 根因（两条通路，都会让 HUD 拿到陈旧门值）

1. **`CONTACT_HOLD_MS`(250ms) 保持窗口**：`g_penDown` 抬笔后还要真 250ms 才归 0 —— 这个保持
   是为「轻压运笔中三信号成段全零 400~600ms」留的，删了会在运笔中闪灭。抬笔后立刻挪笔
   （笔仍在感应区 ⇒ 持续有包 ⇒ `pktAge<250`）时，HUD 的全部条件在这段窗口里**都是真的**。
   ⛔ 没有任何信号能在这 250ms 内区分「真抬笔」与「轻压零段」（buttons/pressure 完全同形，
   `BTN_EDGE_MIN_ZERO=16` 就是从这来的）。

2. **标定失效时包路径提前 return**（`!g_calib.valid` 分支，旧版只写 `reason`）⇒
   `g_penDown / g_toolOk / g_strokeGate` **冻结在 1**；HUD 的 `activeNow` 只看包新鲜度
   ⇒ 包流一恢复就用陈旧几何画一圈。自动填充/换文档会让 PS 重建 Wintab 上下文 ⇒
   正好制造这个重标定窗口。

### 修法

| 位置 | 改动 |
| --- | --- |
| `smooth_engine.c` `smooth_packets` 的 `!g_calib.valid` 分支 | 显式三归零（`g_strokeGate=-1` / `g_penDown=0` / `g_toolOk=0` + `gate_set(0)`） |
| `smooth_engine.c` hud_thread | 新增 `HUD_RESURF_DEBOUNCE_MS=180` 显示去抖：**刚隐藏过的 1.5s 内**必须连续满足 180ms 才重新 show；首次/隔久了立即 show（起笔零延迟） |
| 同上 | 新增 `[hud] 显示` / `[hud] 隐藏` 边沿日志 —— 此前显示动作**零留痕**，4 帧的闪现只能靠「未显示」行的 2s 节流缺口反推，根本看不见 |

## 二、Alt 临时吸管：吸色时冒出 HUD

**根因**：面板切吸管时只 `selectToolByRef`，没动闸门；而 `applyToolGate` 在 `gateOwned` 时
直接 return，即使写了也会被 `write_params()` 丢掉（`pstool_owns()` 时 TOOLGATE 由 `'slct'`
独占）⇒ 引擎仍按套索放行 ⇒ **HUD 显示 + 取色点被拉绳偏移**。

**修法**：新增**独立槽** `I_ALTTOOL`（`CFG_NLONGS 58→59`，两侧同步）：
- `tool_edit_allowed()` 首行 `if (g_cfg[CFG_I_ALTTOOL]) return 0;`
- HUD `gateOk` 追加 `if (g_cfg[CFG_I_ALTTOOL]) gateOk = 0;`（独立兜底：`g_toolOk` 可能还停在 1）
- 新原因码 `RS_ALTTOOL(10)`「临时吸管」
- 入站新消息 `{"type":"altTool","on":0|1}`（用 `json_num` 判非零，⛔ 不用 `json_bool`）
- **三处清 0**：`srv_alt_tool_clear()` ← ① keyhook 的 Alt 物理松开边沿 ② `plug_revoke`（面板不在位）
  ③ `services_start`（无条件）。⛔ 少一处 = 残留 1 = 套索平滑整段失效且界面看不出原因。

## 三、Alt+左键吸色改的是背景色

**结论：不能「让 Alt 绕过 PS」**，两条路都被否决：
1. 按下时**吞掉** Alt（LL 钩子返回 1）—— 铁律 40 实测：PS 前台时我们的低层键盘钩子**整段收不到键**
   （PS 自己的键盘钩子压在链前，链序不可控）⇒ 会「有时吞有时不吞」，同一操作两种结果，比不吞更糟；
2. 事后伪造 `WM_SYSKEYUP` 改 PS 线程键态 —— 跨进程伪造键盘状态，出错就是**全局快捷键错乱**，
   与「不影响正常吸管工具和其他快捷键逻辑」直接冲突。

**采用事后纠正（方案 B）**：PS 照它的规则改背景色，我们在一次取色结束（`hostBusy` 的松开边沿）
之后读回那个颜色写成前景、再把背景复原。
- `hostInteraction.ts` 新增 `onHostRelease()`（只在此刻触发、只触发一次）
- `app.tsx`：`snapshotBackgroundColor()`（同步属性读，无模态）→ `syncAltPickColor()`
  （delay 80ms → 比对 RGB → 一次 `runAsModal` 里赋两个 SolidColor **对象**，不走 batchPlay ⇒ 零黄条风险）
- ⛔ 松开 Alt **不能**立刻丢快照：主流程是「吸色 → 顺手松 Alt」，两个 release 边沿先后不定
  ⇒ `armAltPickExpiry()` 给 800ms 宽限（`altPickUntil`），到点清空
- ⛔ 只在 `altToolHold` 或 800ms 宽限内响应 ⇒ 正常吸管工具零影响
