## 铅笔去锯齿 v6：近水平/垂直"长台阶"直线专项（消除阶梯感残留）

**问题**：接近水平/垂直的略倾斜直线（如 1:10），二值台阶很长（每 10px 跳变一次），blur 覆盖率在台阶段内恒定 → 台阶跳变处 alpha 突变（-59）→ 周期性阶梯感残留。

**根因**：box blur 是局部窗口平均，长台阶段内窗口 mask 模式相同 → cov 恒定 → 平台；跳变处 cov 突变。任何局部窗口法都无法让长台阶段内 cov 渐变（需要全局/亚像素边界信息）。

**解法（混合方案，v18f 定稿）**：
- 主路径不变：blur r=3 + F 表（曲线/陡斜线，用户已满意）
- **长台阶专项**：提取每列 top/bot、每行 left/right 边界；平台段≥5px 的列/行 → 边界带像素改用**相邻列/行线性插值边界的覆盖率**（亚像素连续，跳变处渐变）
- 插值覆盖率用**独立映射 gInterp(cov) = min(255, 198+172·max(0,cov-0.425))**（真实数据拟合：插值cov 0.5 处 alpha≈211，比 F 表高——因为插值 cov 的 0.5 在 mask 内第一圈，blur cov 的 0.5 在 mask 边界，语义不同！）
- 幂等保持（锚定 mask 内≥128/外≤127 + 插值 cov 由 mask 决定 → 0 差异）

**关键教训**：① 插值 coverage 不能直接用 255*cov（硬边映射）——真实圆头笔 mask 内第一圈 224 而非 128，会劣化真实曲线数据（MAE 12.3→18）；② 插值分支必须用真实数据拟合的独立映射（gInterp），真实数据 MAE 保持 12.45（基线 12.31，+0.14 可忽略）；③ 方向选择：top 平台长→列插值（水平段），left 平台长→行插值（垂直段），D 型曲线水平/垂直段各自正确触发。

**验证**：11/11 测试全过（1:10 台阶段无突变+alpha 190-230 匹配真实 / 垂直 1:10 / 45° 不受损 / 削补 / 幂等含长台阶 / 1px 细线 / 色块 / 直通色）；真实数据 MAE 12.45、剖面 +0.5px 222/224；构建通过。

## 铅笔去锯齿 v7：去掉强度滑块 + 柔化宽度改 0.5~2px + 多次点击变粗根因

**用户反馈**：多次点击"铅笔去锯齿"线条越来越粗；要求去掉强度滑块（固定100%）、柔化宽度范围 0.5~2px。

**根因（用真实编译产物验证）**：算法在 strength=100% 下严格幂等（第 2 次起 0 差异、mask 像素数不变）；"变粗"来自**强度 <100% 的混合**：`aF = a0 + (aRecon-a0)×strength` 依赖当前像素值 a0，mask 外过渡带像素逐次趋近上限（63→95→111→127）→ 边缘逐次变实变粗。去掉滑块固定 100% 即彻底解决（aRecon 只由 mask 几何决定 → 严格幂等）。

**改动**：
- AdjustmentPanel.tsx：删除 pencilStrength state/持久化/复位/两个 handler/UI 滑块；`strength: 1` 固定（注释说明原因）；柔化宽度 UI min/max 0.5~2、数字输入 clamp 0.5~2
- pencilAASmoothProcessor.ts：defaultPencilAAParams.softWidth 2.7→2；**blurR 映射 1.1→1.4**（softWidth 0.5/1/1.5/2 → blurR 1/1/2/3，默认 2px 仍对应拟合 blurR=3，默认效果与旧 2.7 一致）；参数 clamp 0.5~2；头注释/interface 同步
