## 0x0212：新增「前景色拾色器」键（默认 Shift+/），并解决它与临时吸管 `/` 的冲突

**用户需求**：功能快捷键子面板「选区填充」区新增条目「前景色拾色器」，放在「临时吸管」**前面**，
默认 `Shift+/`，按下呼出 PS 原生前景色拾色器；并明确要求 `/` 与 `Shift+/` 不冲突。

**改法**（4 层）：
① `utils/ColorPicker.ts` 新增 `pickForegroundColor()`：`showColorPicker` **不注入初始色**
   （初始值天然是当前前景色、也**不还原**，与 `pickColorWithInitial` 的分工正好相反），
   取回值显式写一次前景色并回读比对（铁律 47）。
② `HotkeyBridge`：新增 `action == "pickColor"` / `PICK_COLOR_ID` / 默认 `Shift+/` /
   `ensurePickColorEntry()`（**唯一不按工具模式启停**的 ensure*）/ `get/setPickColorCombo`；
   `normalizeEntry` 白名单；`handleHotkey` 新增分支（无 token 去重，`pickerBusy` 防并发）。
③ `keyhook.c`：按住键判定改「修饰键完全匹配 + 一次性起按准入 + 连两拍确认」。
④ `FuncHotkeyPanel`：清除模式下面（临时吸管上面）新增一行；重录/退格/冲突/保存四条分支；
   与临时吸管**完全相同**的组合键在录制时拦住（工具模式关着时用记忆值兜底）；
   `BrushHotkeySection` 冲突提示补名字；`helpTexts.funcHotkey.pickerRow`。

**⛔ 关键设计**：
- 「按一下」的键必须**进热键表并吞键**（漏给 PS 会触发它自己的绑定）；「按住」的键正相反（不进表）。
- 同键位、修饰键不同是**故意允许**的（`Shift+/` 与裸 `/` 共存），全部靠原生的严格匹配区分；
  只有**完全相同**的组合键才算真冲突。
- `pickerBusy` 期间丢弃 `altHold` 的**按下**边沿（松开照常放行）：拾色器是宿主模态框，
  对话框背后切工具会闪一下。

全仓 168 条历史错误未变、改动文件零错误；`yarn build` 通过。版本 0x0211 → 0x0212。未提交 git。

## 0x0214 · 按 Alt 切多边形套索时被补出一段直线（落笔冻结）

**用户报**：套索落笔中按物理 Alt 临时切多边形套索，**哪怕立刻抬笔**，选区仍从圆心笔直
画到光标、并以光标为折线起点。期望：立刻抬笔 ⇒ 起点=圆心（不补）；一直按着 ⇒ 才补那段。

**根因**：0x0211 的硬否决**立刻**停改写 ⇒ PS 下一包拿到真实光标，与它刚画到的圆心差出
一段（≤ 半径）⇒ 这段差被画成直线并落了第一个锚点。停改写的**时机**错了。

**改法**（只动 `smooth_engine.c` + 版本号）：
* 新增 `poly_hold_run()`，插在 `smooth_packets()` 里 `tool_edit_allowed()` **之前**
  （之后就被清 `g_strokeGate`，进场判据看不到了）。POLYALT=1 的那一拍继续改写，但每包
  写同一个点（`g_ox/g_oy` = 圆心）；`POLY_HOLD_MOVE_PX=14` / `POLY_HOLD_MAX_MS=420`。
* 抬笔那一包**仍写圆心**（PS 认为这一笔在圆心收笔 ⇒ 折线从圆心起，不补线）；光标移开或
  按住超时才解冻透传（PS 自己补「圆心→光标」）。
* ⛔ 只在 `g_strokeGate==1` 进场；⛔ `s_polyUsed` 一轮只冻一次；⛔ 解冻后 `g_wasEnabled=0`
  重锚（例外：Alt 松开且仍在一笔之中 ⇒ 交回平滑，不清锚），否则回套索时会画反向直线。
* 新增 `# [alt] 落笔冻结结束：…` 台账（detour 只置原子，worker 每 2s 落盘）。
* `jw8li_version 0x0213 → 0x0214`；无槽位变化（`CFG_NLONGS` 仍 60）；面板无改动。
