# 2026-09-08

## 修复「自动关开关」在快捷键切笔刷时不生效
- 现象：主开关开启 + 「自动关开关」勾选，手动点工具栏切工具能关；但用快捷键（笔刷热键 / 录好的动作）切出笔刷、工具被带成画笔/混合器时，开关不关。
- 根因（两条）：
  1. 只依赖 `action.addNotificationListener(['select'])` 且只认 `_target` 里带工具名的 descriptor。切笔刷预设的通知是 `{_ref:'brush'}`（预设），工具是被预设**间接**带过去的（混合器/涂抹预设还会连工具一起换），通知里没有工具名 → `resolveSelectedTool` 返回 null。PS 动作回放切工具也不保证广播工具 select。
  2. `AUTO_OFF_TOOLS` 名单穷举不全：混合器画笔在部分 PS 版本下内部名是 `mixerBrushTool`，名单里只有 `wetBrushTool`。
- 修法（src/app.tsx）：
  - 新增工具巡检：主开关开启 + 选项开启时按 300ms 轮询当前工具（`getSelectedBrushToolEnum()` 即 `application.tool._enum`，回退 `app.currentTool`），只在「工具真的变了」时判定；首轮只记基准，避免开开关即自关。3s 卡死放行守卫防模态挂起。
  - `maybeAutoTurnOff`：select 解析不出工具、但 descriptor 含 brush/toolPreset/preset 时回查当前工具再判（即时通道），并与巡检共享 `lastKnownTool` 基准。
  - `isOtherTool`：名单 + 关键词兜底 `/brush|eraser|stamp|smudge/i`，覆盖 ID 别名。
  - 名单补：mixerBrushTool、artBrushTool、artHistoryBrushTool、backgroundEraserTool、magicEraserTool、patternStampTool、sharpenTool、dodgeTool、burnTool、spongeTool。
  - 启停：componentDidMount 末尾 + componentDidUpdate（isEnabled/autoOffOnOtherTool 变化时），componentWillUnmount 清 timer。
- 坑：Edit 工具对 app.tsx 出现过一次「提示成功但未写入」（pollToolChange 的 busy 超时版），必须 Read 复核。
