## 0x0208 修复：缩放动画卡顿/抽搐（宿主交互期巡检让路 + 视图导航否决）

**现象**：加载插件后，PS 自带缩放工具 / Ctrl+空格+左键左右拖拽缩放，动画卡顿、抽搐。

**定位（两条独立缺陷，各自解释一种症状）**

1. **常驻巡检在缩放期间照常抢宿主模态作用域**（对应「卡顿」）
   - 缩放是宿主主线程上的交互式动画，**不派发** `PS_NOTIF_EVENTS` 里的任何事件
     ⇒ `isPsBusy()`（= 上次通知时刻 + 常数窗口，`psProbe.ts`）全程为假。
   - 稳态三条巡检 `1000/1000/2000ms`（`app.tsx`）+ 蒙版同步 `2000/6000ms`
     = 约 2.5~3 次/秒，且被 `MIN_MODAL_GAP_MS=300`（`psAccess.ts:463`）**排成每 333ms 一次**；
     一次 Animated Zoom 仅 300~500ms ⇒ 必撞 1~2 次 `executeAsModal`（独占宿主主线程）。
2. **左键拖拽被当成「一笔」⇒ 视图导航期间改写坐标**（对应「抽搐」）
   - `Ctrl+空格` **不切工具** ⇒ `tool_gate_ok()` 仍为 1、左键按着 ⇒ `smooth_packets` 的
     `useGate` 与 `det_GetCursorPos` 的 `armed` 都为真 ⇒ PS 拿到的是拉绳**滞后**坐标；
     而 scrubby zoom 的缩放级别 = 拖拽位移的函数 ⇒ 级别来回跳 = 抽搐。
3. 附带：HUD 线程永久 8ms 循环，隐藏态每帧仍做 5~6 次跨线程窗口查询（含
   `GetGUIThreadInfo` 查 PS 的 UI 线程、`WindowFromPoint` 命中测试）。
