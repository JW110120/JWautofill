## 0x0208 修复：缩放动画卡顿/抽搐（宿主交互期巡检让路 + 视图导航否决）

**现象**：加载插件后，PS 自带缩放工具 / Ctrl+空格+左键左右拖拽缩放，动画卡顿、抽搐。

**定位（两条独立缺陷，各自解释一种症状）**

1. **常驻巡检在缩放期间照常抢宿主模态作用域**（对应「卡顿」）
   - 缩放是宿主主线程上的交互式动画，**不派发** `PS_NOTIF_EVENTS` 里的任何事件
     ⇒ `isPsBusy()`（= 上次通知时刻 + 常数窗口，`psProbe.ts`）全程为假。
   - 稳态三条巡检 `1000/1000/2000ms`（`app.tsx`）+ 蒙版同步 `2000/6000ms`
     = 约 2.5~3 次/秒，且被 `MIN_MODAL_GAP_MS=300`（`psAccess.ts:463`）**排成每 333ms 一次**；
     一次 Animated Zoom 仅 300~500ms ⇒ 必撞 1~2 次 `executeAsModal`（独占宿主主线程）。
2. **左键拖拽被当成「一笔」⇒ 视图导航期间改写坐标**（对应「抽搐」）
   - `Ctrl+空格` **不切工具** ⇒ `tool_gate_ok()` 仍为 1、左键按着 ⇒ `smooth_packets` 的
     `useGate` 与 `det_GetCursorPos` 的 `armed` 都为真 ⇒ PS 拿到的是拉绳**滞后**坐标；
     而 scrubby zoom 的缩放级别 = 拖拽位移的函数 ⇒ 级别来回跳 = 抽搐。
3. 附带：HUD 线程永久 8ms 循环，隐藏态每帧仍做 5~6 次跨线程窗口查询（含
   `GetGUIThreadInfo` 查 PS 的 UI 线程、`WindowFromPoint` 命中测试）。

## 代码级真凶（两条，都不是参数问题）

**① 工具闸门被「整笔冻结」+ 面板巡检被无限期让路 ⇒ BUG1**
- `smooth_packets`: `if (contactPrev && latched == 1) useGate = ENABLED;`
  —— 一笔之中**完全不看工具**。用户长按笔时左键电平恒真（Wintab 落笔会模拟左键），
  而 0x0208 加的 `hostYield()` 判据正好是「左键 ∨ 空格」⇒ `pollSmoothToolGate` 被
  **无限期跳过** ⇒ `CFG_I_TOOLGATE` 永远停在切走前的 1 ⇒ 涂抹被当成套索继续改写、HUD 继续显示。
- 第二条通路：包路径在 `!g_calib.valid` 时**提前 return**，`g_toolOk` 从不更新 ⇒
  冻结在上一次成功改写时的 1（HUD 只看它）。

**② 心跳过期被当成「工具变了」⇒ 整批透传 ⇒ 停笔画直线 ⇒ BUG2**
- 同一条闩锁：短闩 `g_contact` 抖一次（轻压运笔成段全零是已知现象，0x0124 就是为它加的长闩）
  就掉进 else 分支现判 `tool_gate_ok()`；此刻心跳已过期 3s ⇒ 判 0 ⇒ **整批原样透传**
  ⇒ PS 收到真实笔尖 ⇒ 从圆心拉一根直线到笔尖；随后锚定复位，平滑从头再来。
- 光标路径同病：它用的是 `tool_gate_ok()`（旧代码），与包路径各判一次 ⇒ 漂移一次就分叉
  ⇒ 「HUD 在圆心、选区末端在笔尖」。
- 光标路径还有第三处：`if (!armed) return ok;` —— 三路证据（按钮镜像 / VK_LBUTTON / 包证据）
  任一拍抖成"没按着"就把**真实坐标**透传，这一拍就是那条直线；`gp_step` 的
  `d > rope*4 ⇒ 直接贴合` 是第二根（一帧 200px 瞬移）。
