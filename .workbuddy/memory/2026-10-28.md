## 0x020B：白背景吸白色时前景色不动（临时吸管）

**用户报**：套索工具下 Alt 临时吸管，前景色任意非白 + 背景色为白，吸白色 ⇒ 前景色毫无变化。

**根因**（判据错位，不是取色失败）：
`app.tsx syncAltPickColor()` 用「背景色变了没有」当「这一次有没有取色」的代理判据：
`bgOld`（进吸管前快照）与 `bgNow`（点完读回）都是白 ⇒ 短路 return。
而「吸到的颜色恰好等于原背景色」与「压根没吸」在**颜色值上不可区分**（PS 把同样的值
再写一遍等于没写）。⇒ 只要吸到的颜色 == 原背景色，功能整段失效（不限白色，任意同色都中）。

**修法**：判据从「颜色差异」换成**输入事实**。
1. `keyhook.c`：`hostBusy` 增加 `btn` 字段（1 = 这一帧左键按着）；`btn` 变化单独触发一帧
   （拖拽中 `v` 恒 1、没有边沿）。`char j[48]` → `[64]`。只加字段不动 `v` 语义。
2. `hostInteraction.ts`：新增 `busyHadLeft`（本次按下周期内是否真按过左键）；
   `noteHostBusy(on, leftBtn?)`，`leftBtn === undefined`（旧版 .8li 无该字段）按「有左键」
   兜底 ⇒ 不退化。`ReleaseHandler` 签名改为 `(hadLeftBtn: boolean)`。
3. `HotkeyBridge.ts`：`noteHostBusy(v, btn)`。
4. `app.tsx syncAltPickColor(hadLeftBtn = true)`：无左键（纯空格导航）直接放回；
   **删掉颜色相同的短路**，同色时照常把当前背景色写进前景（幂等），且跳过背景复原。

**版本**：`jw8li_version 0x020A → 0x020B`；CFG_NLONGS 仍 59（无槽位变化）。
**验证**：`bash build.sh` 零告警 + PiPL 往返一致 + 导出表 5 项；`yarn build` 通过
（tsc 只余历史错误，本改动文件零新增）；面板不校验 .8li 版本号，0x020B 兼容旧面板。

**代价（刻意接受）**：点在画布外（工具栏/面板）时 PS 不取色，我们仍会把当前背景色搬成
前景色。比「吸了色没反应」轻。

## 0x020C：标准模式强度失效根因 + 尖角保护门槛 + helpTexts 铁律

**用户报**：标准模式强度「不管数值多少，选区落后光标的距离都差不多」；要求核对尖角保护与说明是否匹配；
并要求统一 helpTexts 的中西文空格、禁用箭头/星号等图标，两条都沉淀为铁律。

**根因 1（强度）**：`g_speed` 用 `|raw − out| / dt`（滞后）当笔速 ⇒ 强度越大 → 滞后越大 →
被判「甩笔」→ 速度适应削平滑 → 滞后又变小，形成把滞后钉死的负反馈（模拟：0→100 只差 3.7→5.7px）。
**改成**「≥6px 距离窗 / ≥4ms 窗时」结算真实位移（`SPEED_WIN_PX/MS/MAX`，锚定时重置）。
修后同条件 5.8→24.0px（速度适应开）/ 7.2→75.0px（关）。

**根因 2（尖角）**：判据要求**单包** >3px，而 205Hz 正常运笔每包 1~2px ⇒ 慢速时整段不触发。
**改成**两级基准：参考方向 ≥3px 线段推进、当前方向 ≥2px 累积位移、命中即重设基准。

**文案**：`helpTexts.ts` 头部新增「排版铁律 / 符号铁律」两段；全文件统一区间写法为「0 – 100」
（原混用 0-100 / 3~9px / 0 - 100%）、补中西文空格（`alpha 下对齐`、`滑块为 0°` 等）、
去掉全部箭头（→ 改「对应/得到/提到」）与星号强调（改「」）、公式段落括号统一全角。

**校验**：`build.sh` 零告警 + PiPL 一致；`yarn build` 通过；tsc 143 条历史错误无新增；
版本 0x020B → 0x020C（协议无变化，CFG_NLONGS 仍 59）。未提交 git（等用户验收）。

## 0x020D：拉绳 HUD 圆心小幅抖动

**用户报**：光标在 HUD 圆环内挪动、绘制点不动时，圆环与圆心一直非常小幅地抖。

**根因**：窗口位置 = `cur − (raw外推 − out)·px`；raw 是整数轴坐标（1 屏幕 px ≈ 13 轴单位），
5ms 基线上量化噪声 = 0.2px/ms 的速度噪声，乘 age(0~8ms) ⇒ 圆心每帧被推 1~2px，
`(int)` 截断后成整格来回跳。模拟：X 峰峰 2px、4s 内反向跳 199 次。
而绳没绷紧时绘制点本来就被冻住（`distPx ≤ radius` 不改 `g_ox`）⇒ 圆心此时不该动。

**改法**：① `snOutX/Y` 与上次提交时相同 ⇒ 复用上一帧位置（`putValid` 三处失效：隐藏/换尺寸/首次）；
② `hud_sticky_px` 整像素迟滞（`HUD_PX_HYST`=0.15）；③ 绳末端改 `cur − 已提交左上角`（位置复用时
`rx/ry` 会自己抖并与光标脱开），顺带让 `vlen` 变成真实屏幕距离、sag/绷直判据不再被噪声扰动。

**校验**：`build.sh` 零告警 + PiPL 一致；模拟同场景峰峰 2px → 0px、反向跳 199 → 0。
版本 0x020C → 0x020D（协议无变化）。未提交 git（等用户真机验收）。

## 0x020E：0x020D 引入的「绳变直棍」

**用户报**：抖动没了，但绳始终绷直成一根棍，一头在圆心、另一头延伸到圆周外，随笔向在右下角小范围转。

**根因**：0x020D 把绳向量改成 `cur − putXc`，而 `putXc/putYc` 是窗口**左上角**、圆心在窗内 `(half,half)`
⇒ 实际得到 `(rx+half, ry+half)`。`half`=124、`leashPx`=100 ⇒ `vlen` 恒在 115~235（> 98）⇒ 恒绷直；
端点 `2·half+rx` = 248~318 落到圆周外；方向被 `(half,half)` 主导 ⇒ 只在 25°~65° 扇形内轻摆。

**改法**：`vx = cur.x − putXc − half`（`vy` 同）。日志新增 `rope=%d`（本帧绳长），
判据「`rope > leash` ⇒ 坐标系错」。

**校验**：`build.sh` 零告警 + PiPL 一致（353,280 字节）；数值复核修正后圈内 `vlen ≤ 100`、
端点恒在窗内。版本 0x020D → 0x020E（协议无变化）。未提交 git（等真机验收）。

## 0x020F：拉绳模式绘制中 HUD 偶尔消失又回来

**用户报**：拉绳模式正常画选区过程中，HUD 有时短暂消失随后重新出现。

**取证**（jwwh-24800，16:53–16:55）：18 次「隐藏→显示」，其中 **10 次笔一直按着**
（`gate=1 stroke=1 penDown=1`），消失 **224~420ms**。「未显示」行显示唯一为假的是
`real=422ms`（阈值 400ms）—— 驱动短暂空转就过期，而快照仍来自真实包、几何可信。

**三条根因 + 改法**：
① `realOk` 分档：新增 `HUD_REAL_SLACK_MS`=1500，`g_synWas==0 ∧ g_strokeGate==1` 时放宽；
   已接管合成包仍按 0x0126 隐藏。
② `lagSkip`/`bigJump` 从 `cheapOk` 移出（并进去 = `ShowWindow(SW_HIDE)`，与「只跳重画
   不隐藏」的注释相反）⇒ 改 `staleFrame` 只跳重绘，连续超 `HUD_SKIP_MAX_MS`(200ms) 强行画一帧。
③ 新增 `HUD_HIDE_DEBOUNCE_MS`=90 隐藏去抖，挡住单帧抖动被 180ms 重现去抖放大的链路。

**日志增强**：隐藏行补齐全部子项（原来只有 ck/cv/gate/stroke/penDown，ck=0 时看不出是谁断的）；
新增「跳过重绘（不隐藏）」「真实包过期宽限」两行，各节流 2s。

**校验**：`build.sh` 零告警 + PiPL 一致（354,304 字节）；版本 0x020E → 0x020F（协议无变化）。
未提交 git（等真机验收）。
