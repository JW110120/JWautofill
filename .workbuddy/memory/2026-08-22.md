## 分块补色 v2：同层/分层兼顾 + 尖角补全（00:45-01:40）

**用户反馈**：① 同层场景尖角头部漏填小三角（v1 的 D≥2 判定把尖角当边缘）；② 线稿与填充分层时无法指定线稿层（v1 误删线稿参考）。

**新样本**（analysis/）：线稿.log（128×125 起点10,9）、含孔隙孔洞内部填充.log（122×117 起点13,11）、补全空隙与孔洞内部填充.log（126×121 起点11,9）。对齐到文档坐标系（起点偏移 place）分析：含孔隙 255 区完全被补全包含（无偏移污染）；补全新增 1068 像素（孔洞/缝隙/尖角）。

**关键诊断**：
- v1 漏填 = 588 个 D==1 像素（尖角应提升）+ 171 个闭掩码外（贴边豁口，close 填不掉）+ 大裂缝；
- 尖角 vs 普通边缘区分特征：8 邻域实体 ≥7（深邻居）或 原 alpha ≥121（实测 0 误伤）；普通边缘只有 1 个深邻居；
- **线稿内部区域 R = holeFill(close(Lm,1)) \ Lm 与补全 255 区吻合 98.9%**（7062 中 6982 个）→ 分层场景用 R 全提升；
- 教训：R 不能包含线稿描边本身（Lm 内 743 个像素补全=0，直接并入 M 会 MAE 崩到 17）。

**v2 算法**（blockColorPatchProcessor.ts 重写）：
- 同层：M=alpha>16 → 豁口填充（透明像素 8 邻域实体≥5，迭代）→ close(M,2) → holeFill → 距离变换 D → D≥2 提升 + 尖角（D==1 且 实体≥7 或 alpha≥80）提升
- 分层：R=holeFill(close(Lm,1)) \ Lm 内全提升（线稿内部 = 填充应覆盖区）
- 参数：maskThreshold=16, closeRadius=2, coreDistance=2, tipAlphaFloor=80, lineThreshold=16

**验证（TS 端到端）**：同层 MAE 9.07 ✓、分层 MAE 7.12 ✓（均 < 10）。同层剩余误差 = 形状增长区（补全比含孔隙略大），无线稿信息无法预知，属固有上限。

**UI**：恢复"线稿参考"下拉（默认自动=当前层上方最近像素层，getAutoLineReferenceLayer 已有），线稿层==填充层时自动退回同层。新增 readLineLayerAlphaMask（imaging.getPixels 按图层 bounds 读，映射到文档坐标）。

## 分块补色 v5：两按钮拆分 + 算法修正（01:09-02:00）

**用户要求**：① 拆两个四字按钮（同层补色/分层补色）；② 线稿下拉用蒙版同步样式；③ 吻合率>99%、尖角吻合率>95%。

**重要 bug（v2/v4 分层实测失败根因）**：
1. **距离语义错误**：`dist_bg`（到背景距离，背景=0）被当"到填充距离"用 → 全部背景像素 cand=true → 线稿描边/背景误填（TS 分层背景 93.5%）；
2. **R\Lm 排除描边**：线稿帽顶内部的尖角头部（fill=0 good=255）被 \Lm 一起排除 → 尖角漏；
3. **Python 原型作弊**：`if good[i]==fill[i]: continue` 依赖 ground truth 掩盖 bug（MAE 7.68 假象）。

**v5 算法**（blockColorPatchProcessor.ts）：fillDist 改用 distanceToMask（掩码内=0）；cand = alpha>16 | fillDist≤1 | (线稿内部 且 联合掩码8邻域实体==9 尖角孔洞)；线稿内部 R 优先全提升；H 内 D≥2；D==1 且(实体≥7 或 alpha≥80)。

**验证（TS 端到端）**：分层 补全区 100%/背景 99.0%/尖角 100%（MAE 8.71）；同层(蛇形线) 补全区 100%/背景 98.99%/尖角 100%（MAE 5.96）。全图精确≈94%（样本过渡区偏移 167 所致，真实对齐场景不成立）。

**UI**：同层补色/分层补色 两按钮（runBlockColorPatch(sameOnly) 公共流程）；线稿下拉复用 MaskSyncSelect 组件（与蒙版同步同款：右对齐 tag、主题色背景、弹层打开自动隐藏 number 输入）；readLineLayerAlphaMask 用 imgData 实际尺寸算 comps（防静默失败）。

## 分块补色 v6：RGB 就近补色 + 凹尖角限制 + 菜单/下拉修复（07:03-07:40）

**5 项反馈修复**：
1. **凹尖角误填**：fillGaps 加 region 参数，豁口填充仅限线稿内部区域 R（分层）；凹尖角在封闭线稿外 → R 外 → 不填。同层 U 形凹槽测试 0 填充。
2. **RGB 白色**：新增 propagateColor 多源 BFS 颜色传播（从 alpha>16 像素扩散 RGB，补色取最近有值像素色）。红色 #e60e0e 样本：分层/同层 RGB 补色 100% 正确。
3. 同层线稿 alpha 提高：无独立线稿信息难根治，RGB 修复后观察。
4. **线稿下拉无法展开**：移除 onOpen={refreshLineReferenceOptions}（与可用的边缘平滑下拉一致）——选项在挂载 useEffect 刷新。
5. **菜单**：alpha 采样移到系统菜单（顺序 折叠/展开 → 隐藏/显示 → 复位顺序 → 参数复位 【-】 图层像素alpha采样）；AdjustmentMenu 新增 onAlphaSample；UI 删除 alpha采样 按钮。

**知识点**：MaskSyncSelect 的 onOpen 在 Promise 微任务中执行 + setState 可能引发下拉行为异常，不可用时去掉 onOpen（挂载时刷新即可）。
