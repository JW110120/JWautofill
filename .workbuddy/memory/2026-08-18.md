# 2026-08-18 工作日志

## alpha对齐 v4（`src/adjustments/alphaAlignProcessor.ts`）

**用户反馈**：v3 对粗线细线识别不错，但细线还差一口气——①两根细线(<5px)交叉 ②细线与粗线交叉 ③色块内部小面积高不透明度杂点(半径<5px)，点击后只统一化一部分，剩高不透明度像素，怎么点都无法统一化。

**根因（合成图实验定位，测试代码在 %TEMP%\aa_test\，Node 可跑）**：
1. **软笔刷细线被拉过暗/斑驳**：v3 的"众数"判据对软笔刷细线失效——细线 core 仅 1~2px 宽，k4 环带 [4,7] 里羽化带（42）像素数 > core（150）像素数 → 众数=42 → 交叉中心 212 被拉到 42、线 core 被误拉低。
2. **环带无众数时卡死**：色块内部 alpha 不均匀（波动/渐变）时，环带直方图无显著众数（占比不达标）→ needLarge 门槛挡死 → 杂点像素永不修改 → "怎么点都无法"。
3. **k112 大环带孤立值污染**：线端羽化/孤立低值在 k112 环带 cnt 极小时成为众数 → 单线 core 被误拉低。
4. **第一遍顺序依赖**：逐行处理时凸包像素被提前拉平，中心像素环带统计漂移（212 计数 8→4）→ 平坦拦截失效。

**v4 方案**：
1. **多尺度环带 RING_SCALES=[1,4,14,42,112]**：k1 捕捉极细线 core，k4/14/42/112 逐级出凸包。
2. **"自身平台"拦截（平坦度判据）**：环带 [alpha..255] 像素 ≥4（绝对数，防软笔刷细线 core 计数少）且 [alpha, alpha+8] 内占 ≥50% → 像素在自身平台（线 core/羽化/凸包中心）→ 放大尺度；否则找参照。
3. **高端区间参照 [max-60, max]**：从环带最大值向下找第一个计数达标簇（≥max(5,10%环带)）——线 core 在环带高值区，羽化带（42/73/109/138）是中低值被排除；凸包值（≥alpha）跳过继续放大。
4. **三态判定**：参照显著低于 alpha（<alpha-5）→ 采纳（多尺度取最低候选，纠正小尺度误选过渡值如 181→150）；参照接近 alpha → 非凸起（flatAll，第二遍跳过）；参照 ≥alpha → 凸包内继续放大。
5. **第一遍固定读原始 alpha（readSrc=aR）**：判定与处理顺序无关（消除顺序依赖）；第二遍读修改后 curA。
6. **中位数回退**：所有尺度无稳定平台（色块波动）→ 用"cnt≥128 的最大有效尺度"直方图中位数（不能只依赖 k112，色块贴边时 k112 cnt=0 → 回退 k42）。受"中尺度(k14/k42)平坦且无非平坦"保护（防线端 core 被 k112 混入的另一条线羽化带污染）。
7. **flatAll 数组**：第一遍判定"非凸起"的像素第二遍跳过（防环带污染误伤）。

**验证**（硬边+软笔刷渲染，二次点击确认无残留）：
- 线宽 1~12px 横竖交叉：中心全 150、残留 0、误拉低 0（v3 的偶数宽度误伤清零）；
- 细粗交叉（软笔刷 4×40）：残留 0（v3 残留 131）；
- 色块+杂点（均匀/±20~30 波动/双杂点）：残留 0（v3 卡死 103）；
- 斜交叉 30°/45°、1px/2px 极细线、T 形相接、线端杂点：全部 0；
- 二次点击全部 0 改动（无斑驳）。
- 剩余边缘（可接受）：soft 5px 残留 4 像素（十字臂 160）、soft 8px 误拉低 8 像素（交叉外围 core→109），合计 12 像素/9 万，视觉无感。

**经验**：环带统计里"众数"对软笔刷细线不可靠（羽化带像素多）——应从**环带最大值向下找高端簇**；"自身平台"用**绝对数阈值**（相对占比在细线场景永远追不上 core 的固定计数）；中位数回退须防"大环带混入另一条线内容"（用中尺度平坦性保护）；两遍处理中第一遍必须读原始数据避免顺序依赖。

## alpha对齐含背景（同日追加）

**需求**：alpha 对齐按钮右侧新增"alpha对齐含背景"按钮。场景：alpha=50 的色块（背景）上画 alpha=118/128 的两根线交叉（同一图层），统一化交叉区域的凸起，**不影响背景色块的不透明度**，适配各种线宽交错。

**与普通 alpha 对齐的区别**：普通模式在"背景+线"场景会把交叉区拉向背景（200→50，中位数回退被背景 50 主导）；含背景模式参照排除背景。

**实现**（`processAlphaAlign` 增加第 6 参数 `withBg`，`handleAlphaAlign(withBg)` + 新按钮）：
1. 每尺度先估计背景水平（环带中位数 med），只统计 >med 的"线上像素"（cntHigh）做参照——簇阈值 bMin 基于 cntHigh 而非全环带（细线在背景主导环带也能命中，修复 1px 交叉中心被拉向背景）；
2. 参照须比 alpha 低至少 BRIGHT_DELTA=10（只修明显凸起，保护"线自身 vs 另一条略不同线"：153 竖线 vs 145 横线差 8 不改）；
3. 参照查找下限 loV = max(max-60, med+1)（高于背景）；
4. 中位数回退取 >med 像素的中位数（线主体水平），同样要求差 ≥10；
5. midFlat 保护：含背景模式只要 k14 平坦就保护线 core（k42/k112 混入另一条线羽化带时也不误伤）；非含背景保持 midFlat && !midNonFlat。

**验证**（背景 50 + 118/128 线交叉，硬边+软笔刷）：
- 硬边 3/1/20px、软 4px：交叉凸起残留 0、背景 50 被改 0、线像素被改 0（用户核心例子完美）；
- 软 2px：残留 2（十字臂 160，差 7 <10 不修）；
- 软 10px：残留 0、16 个线像素 153→140（差 13，轻微）；
- 细粗（软 4×40）：主交叉区 200→145 修好，细线穿过粗线羽化区边缘约 20 个像素过度拉低（159→79，med2 被粗线羽化带主导，边缘情况）；
- 非含背景模式全量回归通过（与 v4 最终版一致，无回归）。

**经验**："背景+线"场景的关键是**排除背景的统计**（cntHigh=环带>中位数的像素数，bMin 基于它）+ **参照差门槛**（BRIGHT_DELTA，保护线自身）+ **中尺度平坦保护**（线 core 不被大环带混入的其他线羽化带污染）。细粗交错+低透明背景+细线穿过粗线羽化区是已知边缘情况（med2 被羽化带主导），尝试过"med2 与 alpha 差 ≤60 上限"会引入等宽线场景回归，暂保留。

## 背景保护（线条侵蚀修复 + 按钮改名，同日第三次）

**用户反馈 2 点**：①按钮"alpha对齐含背景"改名"背景保护"；②选区内线条的一部分被背景 alpha 侵蚀（如软笔刷 4px 交叉区外缘线 core 153→125、细线穿粗线 154→79），选区选得不够大时算法难分线条/背景，要求"识别线条像素并保护，除交叉区外线条全保护"。

**根因（小选区复现 153→125）**：交叉区外缘竖线 core(153) 的 k112 大环带（距离 112-115px，恰好避开交叉区）采到另一条线的羽化带值 125 → bestRef=125 被采纳；而 `midFlat` 保护写在 `bestRef` 返回**之后**，被短路。

**修复（含背景模式 analyzePixel 6 处）**：
1. **midFlat && !midNonFlat 保护提前到 bestRef 返回之前**（含背景：中尺度确认像素在自身平台 → 任何尺度参照都不可信，直接保护）；
2. **含背景候选取"最高"**（bestRef 初始 -1）：大尺度环带污染是"羽化带低值"（125/54），取最高=线 core；非含背景保持取最低（交叉过渡 181>150 由大尺度纠正）；
3. **"接近 alpha 的簇"（差<refDelta）一律保护**（不再跳过找更低）：160 附近有 153×8 线 core 说明像素在线水平附近；跳过会继续找到羽化带 125；
4. **bMin 比例 5%（含背景）**：cntHigh 过滤背景后 10% 过大，软 4px 线 core 在环带仅 8 个，10%×cntHigh=8~11 卡达标线，5%+绝对数下限 5 兜住；
5. **sawAbove 保护**：所有尺度都"v1≥alpha"（像素低于周围线 core，如软 10px 羽化带 135）→ 禁用中位数回退（med2 是羽化带）；
6. **平坦判据含背景改用绝对数**（nearCount≥4）：k42 大环带混入交叉高值（198×1）使 highCount 虚高、占比判据失败；只要 [a,a+8] 内 ≥4 个同水平像素即拦截；
7. **中位数回退前 nearSelf 检查**：环带 [a-refDelta, a+CLOSE_DELTA] 内 ≥4 个接近 alpha 的像素（细线 core 153 穿过粗线羽化带叠加 154）→ 保护，防 med2=粗线羽化带(79)。

**验证**（含背景，背景 50 + 118/128，硬边+软笔刷，全图选区）：
- 硬边 1/3/20px：残留 0、背景 0、线 core 0 改动、侵蚀 0（用户场景完美）；
- 软 2/4/10px：线 core 0 改动、侵蚀 0；软 10px 残留 5（中心 200→180，未完全拉平）；
- 软 20px：残留 141（凸包边缘过渡 159-162 差<10 保护保留）、侵蚀 4；
- 细粗 4×40：线 core 0 改动、侵蚀 2（原 32）；
- 非含背景全量回归通过（A-L、线宽 1-12px、软笔刷、细粗、色块杂点均无回归）。

**教训**：midFlat 保护必须放在 bestRef 返回之前否则被大尺度参照短路；"取最高/取最低"在"羽化带污染大尺度"（软笔刷取最高）与"凸包过渡污染小尺度"（硬粗线取最低）间矛盾，3× 下移（高簇被 ≥3× 大簇替换）会误伤"细线在粗线上"（粗线羽化带是大簇），已回退；硬 20px 凸包中心 200→177 残留为已知局限（"取最高"策略代价，非侵蚀）。
