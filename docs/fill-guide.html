选区填充 使用说明

当 Photoshop 生成「新选区」时，自动按设定的模式（纯色 / 图案 / 渐变 / 清除）填充或删除选区内容，并提供主开关、混合模式、不透明度、羽化、选区改造、描边与颜色抖动等控制。

版本 2.0.0 更新于 2026-10

1. 面板概览

选区填充是悦绘的主面板。它的核心逻辑是：只在生成「新选区」的瞬间触发自动填充——加选、减选、交叉选区都不会触发，也不会在选区已经存在时反复填充。

本插件需要 Photoshop 2022（版本 23.0）或更高版本；其中渐变填充与图案填充需要 Photoshop 24.2 及以上。

面板从上到下包含

  • 主开关：大按钮「功能开启 / 功能关闭」，带状态指示灯。
  • 混合模式：与 Photoshop 图层混合模式一致（默认「正常」）。
  • 不透明度 / 羽化：两个滑杆，控制填充强度与边缘柔和度。
  • 选区改造（折叠区）：平滑、锐度、扩散。
  • 填充选项（折叠区）：填充模式（纯色 / 图案 / 渐变）、新建图层、描边模式、清除模式。
  • 子面板：选中对应填充模式后，展开「颜色动态设置 / 选择图案 / 渐变设置 / 描边设置 / 清除设置」。
原本位于面板底部的四个自动行为选项（自动删选区、更新历史源、自动关开关、自动切套索），现已集中到 「填充设置」浮窗：点右上角 ⋮ 菜单 → 填充设置。同一浮窗还会随当前填充模式显示对应的补充设置。

2. 主开关与快捷键

顶部的主开关决定自动填充是否生效。点击按钮在「功能开启 / 功能关闭」之间切换，左侧指示灯同步显示状态。开关状态会跨面板持久化，并在两个面板间保持一致。

联动行为

选项作用
自动切套索主开关由「关 → 开」时，自动切换到套索工具，便于立刻框选。
自动关开关主开关开启时，若切到以下任意工具，自动关闭主开关：画笔、铅笔、橡皮、混合器画笔、油漆桶、渐变、移动、涂抹、历史记录画笔、模糊、魔棒、仿制图章、钢笔、自由钢笔、曲率钢笔、直线、污点修复画笔、修复画笔、修补工具、红眼、内容感知移动、颜色替换。切到吸管工具不触发。

主开关快捷键（默认 Ctrl+Q）

默认组合键为 Ctrl+Q，由本地的「快捷键服务」通过全局键盘监听捕获，翻转跨面板共享的开关状态——两个面板的显示始终一致。

  • 该条目在配置中长期保留：组合键为空表示你已解绑（不会自动补回默认）；配置里完全没有该条目才视为首次使用、写入默认 Ctrl+Q。
  • 重新设置：右上角 ⋮ 菜单 → 设置主开关快捷键，按提示操作，由快捷键服务录制并写回配置。
  • 若快捷键服务未连接，会提示先到「绘画工具箱 → 笔刷热键」启动它。
使用前提：主开关开启后，需把 Photoshop 工具栏的「羽化」参数设为 0，自动填充才能正常触发。临时改羽化：Enter → 1 → Enter 设为 1（暂停），Enter → 0 → Enter 恢复。

3. 填充模式

在「填充选项」里选择填充模式，并点对应设置图标打开子面板。四种模式互斥，下方选项随模式变化。

3.1 纯色

监测到新选区即填充前景色。点设置图标打开「颜色动态设置」，可让每次填充在设定范围内随机取色（见第 6 节）。

3.2 图案

用本地 jpg / png 图片作为图案预设（不支持 Photoshop 内部图案）。点设置图标打开「选择图案」。

参数说明
填充方式单次：每个选区只绘制一次图案；平铺：图案在选区内重复排列，铺满整个选区。
缩放图案缩放比例（20–300%）。
角度图案的旋转角度（0–360°）。
旋转阵列平铺时让每个图案单元随所在位置整体旋转。
剪贴蒙版把图案填充限制在下方图层的内容范围内。
预览图案最终预览区，放大后可滚动滚轮缩放、按住拖动查看。
  • 「选择图案文件」从系统载入 jpg / png 作为预设；预设支持 Shift / Ctrl 多选、拖拽排序、删除，点空白处取消选择。
  • 图案填充支持 PNG 的不透明度通道（保留透明度）。

3.3 渐变

自行设定渐变的起始颜色、结束颜色与角度，制作并管理渐变预设。点设置图标打开「渐变设置」。

参数说明
渐变预设命名「渐变预设 N」，支持增 / 删 / 拖拽排序、Shift / Ctrl 多选；未选中预设时会提示「请选择一个渐变预设」。
色标点击渐变条可增加色标；颜色色标与不透明度色标一一对应。
样式线性 / 径向。
角度渐变角度（径向模式下该项禁用但仍占位）。
反向 / 保留不透明度两个开关：整体翻转颜色分布；填充时保留渐变自身的不透明度通道。
出于统一逻辑，渐变不透明度色标白色代表 100% 不透明、黑色代表完全透明，与 Photoshop 相反。

3.4 清除模式

按下方所选模式「删除」选区内容（与「新建图层」互斥）。采用绝对计算：白 = 100% 删除，黑 = 完全不删除。因此要用纯色删除内容时，需要先把前景色设为白色。

开启「清除模式」后可进入清除设置子面板选择算法：普通模式下点「清除模式」行右端的齿轮按钮，紧凑模式下直接点「清除模式」文字（两者打开同一子面板）。三组算法相互独立、分别记忆，子面板下方会实时显示所选算法的计算公式。

适用目标可选算法说明
背景图层提亮 / 减黑 / 乘黑背景图层没有透明度。默认「提亮」＝ 模拟用白色橡皮擦背景：输入端越接近白色，输出越接近白色。
蒙版与通道减法 / 乘法快速蒙版、图层蒙版、红 / 绿 / 蓝通道、自定义 Alpha 通道等。以输入端灰度决定清除量：「减法」一次减到底、结果更硬；「乘法」按比例衰减、过渡更柔和。
普通像素图层减法 / 乘法只降低选区内像素的不透明度、不改变颜色，等效于用橡皮擦出不同的透明度。
在背景图层上清除时，若使用图案 / 渐变且其自身透明的部分（α = 0），该处目标像素保持不变；在通道与像素图层上，描边颜色越亮、删除越多。

4. 选区与填充选项

选区改造（平滑 / 锐度 / 扩散，0–100%）

这些设置会在填充前先修改选区本身。

参数说明
平滑效果等同于「选择并遮住」中的平滑选区边缘，减小锯齿与起伏。设为 0 时不修改选区，连续填充会明显更流畅。
锐度锐化选区边缘，使边界更明确。设为 0 时不修改选区。
扩散以喷溅方式向外扩展选区，边缘呈毛糙的不规则形态；数值越大扩展范围越广。

填充选项

选项作用
填充模式选择纯色 / 图案 / 渐变，见第 3 节。
新建图层每次填充前新建一个图层并在其上填充（与清除模式互斥）。
描边模式填充后自动给选区边缘加描边，开启后显示描边颜色预览块。点「描边模式」文字进入子面板（见第 5 节）。
清除模式见 3.4。

填充设置（浮窗）

点右上角 ⋮ 菜单 → 填充设置 打开，包含四个自动行为开关：

  • 自动删选区：填充后取消选区。取消勾选则保留经过改造后的选区。
  • 更新历史源：把历史记录画笔的源图像设为生成选区的那一刻，便于事后用历史记录画笔增强或削弱本次填充。
  • 自动关开关：见第 2 节。
  • 自动切套索：见第 2 节。
未选择图案预设时填充会提示「请先选择一个图案预设」；未选择渐变预设会提示「请先选择一个渐变预设」。

5. 描边设置

开启「描边模式」后，填充会顺带给选区边缘描边。打开设置：普通模式下点「描边模式」行右端的齿轮按钮，紧凑模式下直接点「描边模式」文字（两者打开同一子面板）。

参数说明
宽度0–20px。
位置内部：描边画在选区边界以内；居中：以边界为中心，内外各占一半；外部：画在边界以外，选区整体向外扩大。
混合模式下拉选择，计算方式与 Photoshop 原生一致；清除模式下固定按清除方式处理，该行变为禁用态。
不透明度0–100%。

6. 颜色动态设置

纯色模式下打开。以当前前景色（或面板不透明度）为基准，让每次自动填充在设定区间内随机取色，使连续的纯色填充产生自然变化。

参数范围 / 说明
色相抖动0–360°。
饱和度抖动0–100%。
亮度抖动0–100%。
灰度抖动0–100%（清除 / 快速蒙版 / 图层蒙版 / 单通道时显示此项）。
不透明度抖动0–100%（始终显示）。
计算方法绝对值：抖动范围 = 基准值 ± 抖动值 ÷ 2，区间宽度固定。相对值：抖动范围 = 基准值 ×（1 ± 抖动值 ÷ 200），幅度随基准值等比缩放。
显示公式显示或隐藏下方的公式说明条，用于核对当前取色范围。该开关只控制本面板。

7. 紧凑模式与专注模式

紧凑模式

右上角 ⋮ 菜单 → 紧凑模式。该菜单项只作用于当前面板——子面板打开时作用于该子面板，否则作用于父面板，所以菜单文案会写明确当前对象与开关状态，例如「紧凑模式：选区填充 - 开」。

选区填充、纯色、图案、渐变、描边、清除各自独立开关。开启后，面板会收起标题与分隔线、把填充模式的三行选项并成三列、并把子面板入口并入文字标签，整体更省空间。紧凑模式的开关状态随参数一起保存。

专注模式

在「填充设置」浮窗中，同时勾选 自动关开关 与 自动切套索 即进入专注模式，任一取消即退出。专注模式下：

  • 主开关快捷键只能开启功能，连按也不会关闭。
  • 主开关按钮显示「功能开启（专注）」，指示灯换为靶心图标。
  • 需要关闭时，切到画笔等其它工具（由「自动关开关」自动关闭），或直接点开关本身。

9. 常见问题

为什么开启主开关后没有自动填充？

请确认 Photoshop 工具栏的「羽化」为 0；并且只在生成「新选区」时触发，加选 / 减选 / 交叉选择都不会触发。

填充提示「请先选择一个图案预设 / 渐变预设」？

在对应的「选择图案 / 渐变设置」子面板里先选或新建一个预设再填充。

快捷键（Ctrl+Q）没反应？

说明「快捷键服务」未运行，请到绘画工具箱面板的「笔刷热键」启动它，再回主面板设置主开关快捷键。

菜单里有几项点了没反应？

请检查是否正开着激活 / 试用对话框：此时只有「打开激活与试用面板」与「使用手册」可用，其余条目处于置灰状态。
