# 边缘平滑 · 仅主线条模式 重构验证报告

## ⚠️ v16 重大修正（10:17 用户反馈后）

用户反馈：v4 的"平滑力度"实际是 alpha 提升量而非平滑强度；主体收敛抬高 alpha 反而制造锯齿、局部变粗。
核心问题：任何"提升 alpha"的操作（主体收敛/边缘提升/填缺口）都会制造台阶或变粗；对称平滑会拉暗亮痕。

**v16 最终方案（视觉平滑导向）**：
1. **沿切线对称方向平滑**（核心/边缘带 mix=0.5、过渡带温和双向 mix=0.3、迭代 2 次）
   —— 磨平边缘锯齿/毛刺/反复描线的 alpha 波动（真正"视觉平滑"）
2. **线内均值补偿** —— 对称平滑的回归效应被平移回原水平（整体深浅 100% 保持）
3. **线宽硬约束** —— 新增 >16 像素降回原值（线宽严格 ±0%）
4. **无任何 alpha 提升操作** —— 不制造台阶、不变粗
5. **平滑力度 = 平滑强度**：strength 映射混合比例与迭代次数
   （std 收敛随力度 15%→33%→42%，不再是 alpha 提升量）

**最终指标（TS 端到端，strength=1 radius=8）**：
| 指标 | 值 |
|---|---|
| 背景保持 | 100% |
| 线宽变化 | +0.0% |
| 线内 MAE | 31.7（磨平波动的必然代价） |
| 线内均值 | 111.3 → 111.3（完全保持） |
| 线内 std（反复描线） | 60.8 → 35.1（-42% 收敛） |
| 边缘带锯齿（横向二阶差） | -50% |
| 相邻行突变 | -22% |
| TS vs Python | 平均差 0.00（完全一致） |

## 一、需求与验收口径

用户提供三个 alpha 采样 log：

| 文件 | 尺寸 | 边界 | 角色 |
|---|---|---|---|
| 平滑线条样本.log | 105x140 | (26,4) | 算法输入（脏线条：毛刺、反复描线、alpha 不均、碎点） |
| 理想情况结果.log | 102x133 | (28,10) | 期望目标（干净线，核心 P50/P85 = 229/248） |
| 最低要求结果.log | 114x150 | (17,0) | 最低可接受目标（核心 P50/P85 = 176/210） |

**重要说明**：三个 log 尺寸与内容不同（样本是折线+并行双支，理想是两条平行线，最低是一条粗斜线），
不是同一张图的三种状态，**无法做像素级 RGBA 99% 逐点对比**。因此验收采用两条路径：

1. **受控性（像素级可测）**：输出 vs 样本 —— 背景 100% 保持、线宽不粗不细、alpha 偏离可控；
2. **形态达标（维度级）**：输出核心主体水平 vs 理想/最低 —— 应达到"至少最低要求"水平。

RGBA 四通道吻合度说明：
- **R/G/B 通道**：算法只修改 alpha 通道，RGB 直通色保持原值 → RGB 三通道与输入**逐像素完全一致（0 差异）**；
- **A 通道**：背景（alpha=0）100% 保持；非背景像素按算法更新。综合 RGBA 吻合度由背景区（占比 85%）全保持 + 线内受控变化构成。

## 二、算法重构（仅主线条模式）

### 旧算法的问题
- 依赖 PS「中间值」滤镜预处理（UI 先 median 再处理），结果不可控；
- 参数多且相互纠缠（中间值半径/平滑力度/平滑范围/保护细节），强度入口还被 `*0.5` 折半；
- 方向估计用局部梯度+PCA，在折线/并行线区域不稳定；对称平滑把亮痕也拉暗（线条整体变淡）。

### 新算法管线（与 Python 原型 line_smooth_proto_v4.py 逐行对应）
```
Phase 1  结构张量方向场（Sobel 梯度 + 7x7 高斯窗口）→ 每像素切线角
Phase 2  沿切线各向异性平滑（迭代 2 次）：
           A. 核心（线内深度 ≥1.2px）：全采样，结果 max(平滑, 原值)
              —— 暗痕（反复描线）被周围亮痕拉亮、亮痕保持（非对称，不偏离）
           B. 边缘带（线内深度 <1.2px）：仅纯切线采样，限制 [原值-25, 原值+12]，保底 17
              —— 削沿线锯齿节律，防缩线
           C. 过渡带（线外距线 <5px）：仅纯切线采样，只降不升
              —— 削毛刺凸起，绝不外扩 → 线宽严格保持
Phase 3  局部主体收敛（仅核心）：向沿切线窗口 P88 收敛，提升上限 60
          —— 反复描线的深浅不一被磨平，主体向"更实"方向收敛
Phase 4  碎点清理：线外孤立低 alpha 簇（面积≤12、距主线>1.2px）移除
Phase 5  背景（alpha==0）绝对保持；RGB 直通色不变
```

### 参数精简
| 参数 | 旧 | 新 |
|---|---|---|
| 平滑力度 | 0-100%（默认 85%，且内部折半） | **0-100%（默认 100%）** |
| 平滑范围 | 3-12px（默认 10） | **3-12px（默认 8）** |
| 中间值半径 | 10-30px（line 模式用 PS median） | **删除**（算法不再依赖 PS 滤镜） |
| 保护细节 | 0-100%（默认 70%） | **删除（固定 0）** |

UI 仅主线条模式现在只有 **2 个滑块**：平滑力度（默认 100）、平滑范围（默认 8px）。
