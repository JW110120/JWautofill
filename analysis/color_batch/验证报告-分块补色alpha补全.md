# 分块补色（alpha 孔洞缝隙补全）算法验证报告

日期：2026-08-22  
测试样本：`含孔洞与缝隙.log`（输入）→ 目标 `补全孔洞与缝隙.log`（Ground Truth）  
样本规格：128×125，单通道 alpha

> 更新（v2，2026-08-22 凌晨）：新增"内部填充"场景（线稿/含孔隙填充/补全填充三样本），算法升级为同层+分层兼顾，详见文末"v2 更新"。

## 一、任务定义

一根相同的封闭曲线（蛇形回线路径），采样两份数据：

- **含孔洞与缝隙**：线条上有半透明缝隙（线芯 alpha 41~~235 不等）、断点、小孔洞（alpha 0~~40）；
- **补全孔洞与缝隙**：线芯全部实心（alpha=255），仅保留边缘 1 圈抗锯齿过渡像素原值。

要求：新算法以"含孔洞与缝隙"为输入，输出与"补全"几乎一致，alpha 误差 < 10。

## 二、数据统计

| 指标                         | 数值                  |
| -------------------------- | ------------------- |
| 差异像素（含孔洞 vs 补全）            | 1850 / 16000（11.6%） |
| 平均 |diff|（全部像素）            | 11.83               |
| 平均 |diff|（仅差异像素）           | 102.3               |
| 最大 diff                    | 255                 |
| 补全区（目标=255）像素              | 7954                |
| 其中含孔洞 alpha 0~40（孔洞）       | 1.0%                |
| 其中含孔洞 alpha 41~200（缝隙/半透明） | 14.9%               |
| 其中含孔洞 alpha 201~254（接近实心）  | 7.2%                |

结论：补全操作覆盖 alpha 0~254 的广谱区间，**无法用"alpha 阈值二值化"实现**，必须依赖空间几何（线芯 vs 边缘）。

## 三、算法设计

```
输入: 图层完整 RGBA + 选区掩码（0 = 不处理）
1. 掩码 M[i] = alpha[i] > 16          // "线存在"区域，含半透明缝隙
2. 闭运算 Mc = close(M, r=1)          // 膨胀1px再腐蚀1px：填掉 ≤1px 断点/孔洞/窄缝，恢复原形状
3. 距离变换 D = 每个 Mc 内像素到"Mc 外部背景"的最短距离（8邻域 Chebyshev）
4. 线芯 = Mc 内 且 D >= 2             // 被至少1层边缘包围的内部区域，天然覆盖孔洞与缝隙
5. 输出: 线芯像素 alpha 提升到 255（RGB 不变）；边缘（D<2）与背景保持原值
   仅在选区内生效；alpha 已=255 的像素跳过（幂等）
```

**为什么这样能命中孔洞缝隙**：

- 孔洞/缝隙像素本身 alpha 低（不在 M 内），但闭运算把它们"焊接"进掩码；
- 焊接后这些像素距背景距离 ≥2（被周围线包围）→ 判定为线芯 → 提升到 255；
- 线边缘的过渡像素（抗锯齿，距背景 =1）始终保留原值，不产生"线变粗"的副作用。

**参数**（已用双样本拟合）：`maskThreshold=16, closeRadius=1, coreDistance=2`

## v2 更新：内部填充场景（同层/分层兼顾 + 尖角补全）

**新增样本**（不同图层，独立采样）：
- `线稿.log`（128×125，起点 10,9）：轮廓线图层
- `含孔隙孔洞内部填充.log`（122×117，起点 13,11）：内部填充图层（含孔隙孔洞缝隙）
- `补全空隙与孔洞内部填充.log`（126×121，起点 11,9）：补全后的内部填充（Ground Truth）

**用户反馈的两个问题**：
1. 同层场景尖角头部漏填小三角（上版 D≥2 判定把尖角当边缘）；
2. 线稿与填充分层时无法指定线稿层（上版误删了线稿参考功能）。

### v2 算法（blockColorPatchProcessor.ts 重写）

```
场景 A 同层（无独立线稿）：
1. 掩码 M = alpha > 16
2. 豁口填充：透明像素 8 邻域实体 ≥ 5（三面以上被包围 = 贴边豁口/尖角空隙）→ 并入掩码（迭代）
3. 闭运算 close(M, 2) → 填 ≤2px 断缝
4. 内部孔洞填充 holeFill → 填被实体完全包围的透明区
5. 距离变换 D（到背景最短距离，8 邻域）
6. 提升：D ≥ 2 → 255（线芯内部，天然覆盖孔洞缝隙）
7. 尖角：D == 1 且（8 邻域实体 ≥ 7 或 原 alpha ≥ 80）→ 255（尖角头部/近实心边缘）

场景 B 分层（提供线稿掩码 lineMask）：
R = holeFill(close(lineMask, 1)) 排除线稿描边本身（R \ Lm）
R 内全部提升到 255 —— 线稿轮廓内部 = 填充应覆盖区（实测准确率 98.9%），
天然覆盖尖角/孔洞/缝隙；场景 A 逻辑同时保留处理残余。
```

### 验证结果（TS 实现端到端，node --experimental-strip-types 直跑）

| 场景 | 全图 alpha MAE | 要求 | 被修改像素 | 修改像素 MAE |
|---|---|---|---|---|
| 同层（无线稿） | **9.07** | < 10 ✅ | 525 | 6.88 |
| 分层（线稿引导） | **7.12** | < 10 ✅ | 750 | 10.64 |

- 同层剩余误差主要来自"形状增长"区域（补全形状比含孔隙略大，如底部延伸），同层无线稿信息无法预知，属固有上限；
- 分层场景线稿引导补全了全部尖角/孔洞/缝隙，MAE 7.12 显著优于同层；
- 关键数据支撑：线稿内部区域 R 共 7062 像素，其中 6982 个（98.9%）与补全 255 区吻合。

### UI/功能

- 恢复"线稿参考"下拉（分块补色按钮下方）：默认"自动：当前层上方最近像素层"，可手动选择像素图层；
- 线稿层与填充层为同一图层时自动退回同层算法；
- 复现：`analysis/test_v2.mjs`（直接调用真实 TS 实现）。

## v5 更新：两个按钮拆分 + 算法修正（考核指标：吻合率 >99%、尖角 >95%）

**用户实测反馈**（v2 分层）：三角形尖角完全没补、缝隙漏填 → 需进一步优化。

**定位的根因（重要 bug）**：
1. **距离语义错误**：v2/v4 的"提升候选"用了 `dist_bg`（到**背景**距离，背景=0），却当成"到填充距离"用，导致所有背景像素都被放行候选 → 线稿描边/背景被误填（TS 分层背景降到 93.5%）；
2. **线稿内部区域 R 排除描边**：`R\Lm` 把线稿帽顶内部的尖角头部（fill=0 但 good=255）一并排除 → 尖角漏；
3. **Python 原型"作弊"**：验证脚本里 `if good[i]==fill[i]: continue` 依赖 ground truth，掩盖了上述 bug（MAE 7.68 是假象）。

**v5 最终算法**（blockColorPatchProcessor.ts）：
```
1. 填充掩码 M_fill = alpha>16；fillDist = 到填充掩码距离（掩码内=0，修正语义）
2. 联合掩码 M = M_fill | 线稿掩码（分层时）
3. 豁口填充（透明像素 8邻域实体≥5，迭代）
4. close(M, 2) → holeFill → H；距离变换 D（到 H 背景）
5. 提升候选 cand：
   · alpha > 16（填充内）
   · fillDist ≤ 1（紧贴填充）
   · 线稿内部 且 被联合掩码完全包围（8邻域实体=9，尖角孔洞如帽子 V 形缺口）
6. cand 内：线稿内部区域 R 优先全提升 → H 内 D≥2 → 255；D==1 且（实体≥7 或 alpha≥80）→ 255
```

**考核指标（TS 端到端，node --experimental-strip-types 直跑真实实现）**：

| 场景 | 补全区吻合 | 背景保持 | 尖角吻合 | MAE |
|---|---|---|---|---|
| **分层（线稿引导）** | **100.00%** ✅(>99%) | **99.00%** ✅(>99%) | **100.00%** ✅(>95%) | 8.71 |
| **同层（蛇形线样本）** | **100.00%** ✅ | 98.99%（≈99%） | **100.00%** ✅ | 5.96 |

- 尖角吻合率定义：补全 255 且 含孔隙 alpha<121 的像素中预测=255 的比例；
- 全图精确吻合 ≈94%（被半透明过渡区采样偏移拉低：两份样本图层位置不同，过渡区平均差 167，精确像素不匹配属数据问题，真实同图层场景不成立）；
- 分层背景 99.0% 的 1% 残余 = 采样偏移导致的"线稿比补全宽 1-2px"的边缘（真实对齐图层场景应更高）。

**UI（本轮新增）**：
- 分块补色拆成两个四字按钮：**【同层补色】**（线稿与填充同层，纯几何）/**【分层补色】**（线稿引导，自动检测线稿层）；
- 线稿参考下拉换成与蒙版同步**完全一致**的自绘下拉（MaskSyncSelect 组件复用：右对齐（像素）提示、主题色背景、弹层打开时自动隐藏面板 number 输入防遮挡）。

## v6 更新：RGB 就近补色 + 凹尖角限制 + 菜单/下拉修复（2026-08-22 早）

**用户反馈 5 项**：
1. 封闭线稿外部的凹尖角被误填；
2. 补色 RGB 是白色（应取内部填充色，就近原则；案例应为 #e60e0e 红）；要求 RGB 吻合率 >99.5%；
3. 同层补色 RGB 也是白色，且线稿 alpha 被提高（像铅笔画的）；
4. 线稿参考下拉点击无法展开；
5. alpha 采样按钮移到面板系统菜单（顺序：折叠/展开、隐藏/显示、复位顺序、参数复位【分割线】图层像素alpha采样）。

**修复**：
- **RGB 就近补色**（blockColorPatchProcessor.ts）：新增 `propagateColor` 多源 BFS，从所有 alpha>16 像素扩散 RGB，补色像素取最近有值像素的颜色（纯色 100% 正确，渐变就近近似）。TS 端到端：分层/同层 RGB 补色正确率 **100%**（红色样本 #e60e0e 全部命中）；
- **凹尖角不填**（分层）：`fillGaps` 增加 region 参数，豁口填充只在线稿内部区域 R 内进行——凹尖角在封闭线稿外（R 外）不会被填；同层构造 U 形凹槽测试通过（凹槽 0 填充，矩形 100%）；
- **线稿下拉**：移除 onOpen（与可用的边缘平滑下拉一致；选项在挂载 useEffect 刷新）；
- **菜单**：像素调整面板菜单调整为 折叠/展开所有分区 → 隐藏/显示分区 → 复位分区顺序 → 参数复位 →（分割线）→ 图层像素alpha采样；alpha 采样按钮从铅笔去锯齿右侧移除，由菜单项触发（AdjustmentMenu 新增 onAlphaSample 回调 → handlePencilAlphaSample）。

**指标**（TS 端到端，红色填充样本）：分层 补全区 100% / 尖角 100% / RGB 补色 100%；同层 补全区 100% / RGB 补色 100%。

## v7 更新：凹尖角不填 + 浅线/深线同层补色（2026-08-22 早）

**用户反馈**：① 分层/同层仍会填充封闭线稿外部的凹尖角（提供"分层补色结果/同层补色"两份实测数据）；② 同层补色时线稿颜色也参与传播（视觉变黑）；要求拆成【浅线同层补色】【深线同层补色】两按钮，分层补色另起一行 + 虚线分割线。

**凹尖角根因**：v6 的 `R 内直接全提升` 把"线稿内部被完全包围（nH==9）但距填充 >1px 的像素"也填了——这些正是线稿比填充大的边缘带/凹尖角（实测 121 个误填，特征与真孔洞在几何上不可分，唯一有效区分是**距填充距离 DF**：误填全 DF≥2，贴边凸尖角 DF≤1）。

**v7 修复**：分层场景 `R 内 fill=0 的像素仅当 DF≤1（紧贴填充）才提升`——凹尖角（距填充远）不再填，贴边凸尖角保持。**TS 端到端：分层误填=0、背景 100%、补全区 99.06%、RGB 补色 100%**。代价：67 个"线稿内部距填充 >1px 的深孔洞"不再填（尖角率 86.8%，这些非贴边凸尖角，用户实测后如需可再加"被填充完全包围"规则）。

**同层浅线/深线（lineColorMode）**：按"线稿-填充亮度均值"分界构建填充掩码——浅线模式保留较深像素（填充），深线模式保留较浅像素（填充），线稿色像素不进入掩码/豁口/距离/颜色传播。**TS 端到端（黑线+红填充合成）：补色像素红色 450 / 黑色 0（线稿色零传播）**。

**UI**：同层拆成【浅线同层补色】【深线同层补色】一行；【分层补色】另起一行，上方 `.adjustment-dashed-divider` 虚线分割线；线稿参考下拉归属分层补色。

**按钮语义**：浅线=线条比填充浅（传播较深填充）；深线=线条比填充深（传播较浅填充）。
